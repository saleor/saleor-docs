## Built by Saleor

These apps were built by Saleor team using [Saleor App Template](/developer/extending/apps/developing-apps/app-template), however, they are not currently available in the [App Store](https://apps.saleor.io) and may not be maintained. You can use them as a reference for building your own apps.

:::tip
Built an app and want to share it? Submit a pull request to the [Awesome Saleor](https://github.com/saleor/awesome-saleor) repository.


:::
