[Paper](https://github.com/saleor/storefront) is Saleor's open-source storefront, built with Next.js and designed to be changed with coding agents. It requires Saleor 3.23 or later. See the [live demo](https://storefront.saleor.io) or [run it locally](/quickstart/storefront).

## Features

<CardGroup cols={2}>

  <Card title="Checkout" icon="shopping-bag">
Multi-step, server-rendered checkout with Stripe and a dummy gateway for test orders. Guests get an order confirmation page after paying.
</Card>

  <Card title="Markets" icon="earth">
URLs carry the language and channel, e.g. `/en/us/products/hoodie`. Shoppers switch language, market, and currency in one region picker.
</Card>

  <Card title="Internationalization" icon="languages" href="/developer/extending/api/i18n" arrow>
The interface ships in eight languages. Product copy and URL slugs come from Saleor translations, and pages link their other-language versions for search engines.
</Card>

  <Card title="Product pages" icon="package">
Variant selection across several attributes, such as color and size, with per-variant prices and images.
</Card>

  <Card title="Caching" icon="zap">
Catalog pages are cached and refreshed by webhooks. Cart and checkout are always live.
</Card>

  <Card title="Images" icon="image" href="/developer/storefront/guidelines#images" arrow>
Images come in several sizes straight from Saleor's CDN, so the host doesn't bill for image optimization.
</Card>

  <Card title="Storefront copy" icon="file-text" href="/developer/models" arrow>
Homepage, cart, and checkout copy is stored in Saleor Models, so merchants edit it in the Dashboard.
</Card>

  <Card title="Customer accounts" icon="users">
Sign-in, registration, password reset, address book, order history, and account deletion.
</Card>

</CardGroup>

## Built for coding agents

Paper is structured so a coding agent can change it quickly and follow the repository's patterns.

<CardGroup cols={2}>

  <Card title="AGENTS.md" icon="bot">
An always-on guide that tells agents where to find Next.js, Paper, and Saleor API context for a task.
</Card>

  <Card title="Paper skill" icon="book-open">
Task-specific rules for checkout, caching, product pages, design, translations, SEO, and more. Agents load only the rule they need.
</Card>

  <Card title="Saleor Agent Skills" icon="blocks" href="/developer/ai#agent-skills" arrow>
Paper builds on Saleor's general storefront skills. `pnpm skills:bootstrap` installs them with the other pinned skills.
</Card>

  <Card title="Fork upgrades" icon="git-merge">
Migration guides let an agent bring upstream Paper changes into your customized copy.
</Card>

</CardGroup>

## Paper app

<Callout type="info">

The Paper app is available only on Saleor Cloud.

</Callout>

The Paper app connects the Saleor Dashboard to your Paper storefront. Install it from **Dashboard → Extensions**.

<CardGroup cols={2}>

  <Card title="Instant updates" icon="refresh-cw">
Registers webhooks that refresh the storefront cache when you change products, categories, collections, pages, menus, promotions, or translations.
</Card>

  <Card title="Preview on storefront" icon="external-link">
Opens the product on your storefront from the product page in the Dashboard, in the right language and channel.
</Card>

  <Card title="Cache purge" icon="eraser">
Clears the cache for one product, category, collection, or page, for menus, or for the whole storefront.
</Card>

  <Card title="Storefront Models" icon="layout-dashboard">
Creates the Models that hold Paper's storefront copy, filled with default content.
</Card>

  <Card title="Several storefronts" icon="layers">
Connects up to five storefronts, such as production and staging, to one Saleor environment.
</Card>

  <Card title="Event log" icon="list">
Shows the last 50 cache refreshes and checks the connection to the storefront.
</Card>

</CardGroup>
