## Documentation MCP

The Documentation MCP is a read-only server for this documentation site. It lets agents:

- search the documentation;
- read a page as agent-optimized Markdown;
- list available pages; and
- inspect the documentation navigation.

Connect an MCP-compatible client to:

<SiteUrlCode path="/mcp" />

For clients that use JSON configuration:

<SiteUrlCode path="/mcp" mcpConfig />

This endpoint searches and reads documentation. It does not connect to a Saleor instance or execute GraphQL operations.

MCP discovery metadata is available at:

- [MCP discovery manifest](/.well-known/mcp.json)
- [MCP server card](/.well-known/mcp/server-card.json)

## Agent Skills

Give your coding agent Saleor workflows and implementation guidance. Run this from your project, then choose the skills and agents to install:

```sh
npx skills add saleor/saleor-docs
```

Skills install into the current project by default. Add `-g` to make them available across projects.

Browse each skill's source and supporting files on GitHub:

| Skill | Use it for |
| --- | --- |
| [`saleor-app`](https://github.com/saleor/saleor-docs/tree/main/skills/saleor-app) | Apps, registration, permissions, payments, and webhooks |
| [`saleor-storefront`](https://github.com/saleor/saleor-docs/tree/main/skills/saleor-storefront) | Storefront API patterns, checkout, channels, and variants |
| [`storefront-builder`](https://github.com/saleor/saleor-docs/tree/main/skills/storefront-builder) | Storefront data contracts and user experience |
| [`saleor-configurator`](https://github.com/saleor/saleor-docs/tree/main/skills/saleor-configurator) | Store configuration as code |
| [`saleor-core`](https://github.com/saleor/saleor-docs/tree/main/skills/saleor-core) | Saleor backend internals and implementation details |

To install a specific skill:

```sh
npx skills add saleor/saleor-docs --skill saleor-app
```

For more options, see the [Skills CLI reference](https://github.com/vercel-labs/skills/blob/main/docs/commands.md).

## Saleor MCP

The Documentation MCP above answers questions from the Saleor documentation. To work with the Saleor GraphQL schema through MCP, run a GraphQL MCP server separately and point it at a downloaded Saleor schema.

For example, with `mcp-graphql`:

```json
{
  "mcpServers": {
    "saleor-api": {
      "command": "npx",
      "args": ["mcp-graphql"],
      "env": {
        "SCHEMA": "/path/to/saleor.graphql"
      }
    }
  }
}
```

Download the schema from [the documentation](/schema/saleor.graphql) or from the Saleor repository. The `main` branch schema can contain unreleased changes, so prefer the schema matching your Saleor version.
