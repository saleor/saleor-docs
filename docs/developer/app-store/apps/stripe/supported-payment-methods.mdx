Saleor team ensures Stripe App works properly with selected payment methods.
App doesn’t support every method available in Stripe. Saleor team keeps adding them as soon as possible.

The current list of payment methods, with the `paymentMethod` value the storefront sends in [`transactionInitialize` data](./webhooks#transactioninitializesession), is:

- [ACH Direct Debit](https://docs.stripe.com/payments/ach-direct-debit): `us_bank_account`
- [Apple Pay](https://docs.stripe.com/apple-pay): `apple_pay`
- [Card](https://docs.stripe.com/payments/cards): `card`
- [Google Pay](https://docs.stripe.com/google-pay): `google_pay`
- [Klarna](https://docs.stripe.com/payments/klarna): `klarna`
- [Link](https://docs.stripe.com/payments/link): `link`
- [MobilePay](https://docs.stripe.com/payments/mobilepay): `mobilepay`
- [Pay by Bank](https://docs.stripe.com/payments/pay-by-bank): `pay_by_bank`
- [PayPal](https://docs.stripe.com/payments/paypal): `paypal`
- [Revolut Pay](https://docs.stripe.com/payments/revolut-pay): `revolut_pay`
- [SEPA Direct Debit](https://docs.stripe.com/payments/sepa-debit): `sepa_debit`

ACH Direct Debit and Pay by Bank are always charged immediately, even if the channel uses the authorization flow.

Ensure your Stripe Dashboard available methods match the list above.

:::warning[If you enable more methods, Stripe UI will show unsupported methods for the customer.]
Trying to pay with it will cause App to return an error.

:::
