## Prerequisites

- Saleor **3.23** or newer (below 4.0)
- A staff user who can install apps

## Install Pulse

1. In the Saleor Dashboard, open **Extensions → Explore** and install Pulse.
2. Approve the permissions Pulse requests. Each one maps to something you see in the product:

| Permission         | Why Pulse needs it                                    |
| ------------------ | ----------------------------------------------------- |
| `MANAGE_ORDERS`    | Revenue, fulfillment, and operational analytics       |
| `MANAGE_PRODUCTS`  | Product rankings, Product Insights, and stock context |
| `MANAGE_USERS`     | Top customers and customer mix views                  |
| `MANAGE_DISCOUNTS` | Promotion and voucher context on trends               |

3. After install, Pulse mounts on the main Dashboard home as a **Pulse** tab. You can also open it from **Extensions → Installed → Saleor Pulse**, and **Product Insights** appears on product pages.

## First Import

The first time Pulse opens, it imports your store history so charts are not empty zeros.

You will see progress through orders, customers, products, variants, and promotions. When the import finishes, the dashboard takes over.

If the import fails:

- Staff with `MANAGE_APPS` can retry from the first-run screen
- Other users should ask an admin to retry

How far back that history goes depends on your plan (see [Assumptions and Limitations](./overview.mdx#assumptions-and-limitations) on the overview).

## Who Can See What

Anyone who can open the app can reach the Pulse iframe. What they see still depends on Dashboard permissions:

| Capability                               | Staff permission  |
| ---------------------------------------- | ----------------- |
| Financial and Operations analytics       | `MANAGE_ORDERS`   |
| Top customers (names and emails)         | `MANAGE_USERS`    |
| Product Insights on product pages        | `MANAGE_PRODUCTS` |
| Change Settings (sync, alerts, timezone) | `MANAGE_APPS`     |

Install and uninstall still follow normal app-install permissions in Saleor.

## Settings Worth Knowing

Open **Settings** when you want Pulse to match how your team thinks about the store.

- **Analytics timezone** — used for hour-of-day views so “morning” means morning in your store, not UTC by accident
- **Operational alerts** — which alert types run, how sensitive they are, and which channels to mute
- **Data freshness** — if numbers look behind, use Sync Now (or a full resync when you need a clean rebuild). Staff need `MANAGE_APPS` for these actions

You do not need to manage infrastructure here. Stay in Settings for timezone, alerts, and the occasional refresh.
