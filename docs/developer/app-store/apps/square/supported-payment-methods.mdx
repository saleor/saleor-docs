The Saleor team tests the Square App with selected payment methods. The app doesn't support every method available in Square.

The current list of payment methods is:

| Method                                                                                      | `method` value      | Notes                                                                 |
| ------------------------------------------------------------------------------------------- | ------------------- | --------------------------------------------------------------------- |
| [Card](https://developer.squareup.com/docs/web-payments/take-card-payment)                  | `card`              | Supports buyer verification (3-D Secure)                              |
| [Saved card](https://developer.squareup.com/docs/web-payments/charge-and-store-cards)            | `saved-card`        | Requires a logged-in customer                                         |
| [Square gift card](https://developer.squareup.com/docs/web-payments/gift-card) | `gift-card`         | Can pay part of the total. One gift card per checkout                 |
| [Apple Pay](https://developer.squareup.com/docs/web-payments/apple-pay)                     | `apple-pay`         | Requires Apple Pay domain registration in Square                     |
| [Cash App Pay](https://developer.squareup.com/docs/web-payments/add-cash-app-pay)           | `cash-app-pay`      | Available only in countries supported by Cash App Pay                 |
| [Afterpay/Clearpay](https://developer.squareup.com/docs/web-payments/add-afterpay)          | `afterpay-clearpay` | Available only in countries supported by Afterpay/Clearpay            |

Apple Pay, Cash App Pay, and Afterpay/Clearpay are offered only when the app can read the country of the connection's Square location. The `methods` field returned by [`paymentGatewayInitialize`](./webhooks#paymentgatewayinitializesession) lists the methods available for the channel.

:::warning
Square decides whether a method is available for a given location, currency, and amount. A method listed by the app can still be unavailable for a specific checkout. The Web Payments SDK returns an error when you try to create it, so render only the methods that initialize successfully.
:::
