## Note Down Avalara Plugin Configuration

1. Login to your Saleor Dashboard
2. Go to Plugin configuration
   ![A screenshot of the Saleor Dashboard displaying the "Configuration" section. The "Plugins" section is highlighted, indicating the option to view and update plugins and their settings.](/docs/developer/app-store/apps/avatax/assets/avalara-plugin-1.jpg)
3. Find Avalara plugin and go to its details
   ![A screenshot of the Saleor Dashboard displaying the "Plugins" section. There is a list of plugins with the name "Avalara" highlighted.](/docs/developer/app-store/apps/avatax/assets/avalara-plugin-2.jpg)
4. For every configured channel note down plugin settings:
   - username or account
   - use sandbox
   - company name
   - autocommit
   - ship from - city
   - ship from - country
   - ship from - country area
   - ship from - postal code
   - shipping tax code
   - authorization (password / license)

## Select AvaTax App Tax Calculation Method

1. Install AvaTax app via Saleor appstore
   ![A screenshot of the Saleor Dashboard in the "Apps" section. The "Install" button is highlighted, indicating the option to install AvaTax app.](/docs/developer/app-store/apps/avatax/assets/tax-calc-method-1.jpg)
2. Go to Taxes configuration
   ![A screenshot of the Saleor Dashboard in the "Configuration" section. The "Taxes" section is highlighted.](/docs/developer/app-store/apps/avatax/assets/tax-calc-method-2.jpg)
3. For every channel you want to use AvaTax app - change method of tax calculation to app. If you have country exceptions - select app there as well
   ![A screenshot of the Saleor Dashboard in the "Taxes" section. A highlighted dropdown menu allows the selection of tax calculation methods, including options for using the "Avalara" app and a flat tax rate.](/docs/developer/app-store/apps/avatax/assets/tax-calc-method-3.jpg)

There is possibility that you will see warning banner above dropdown that selects method of tax calculation. It mean that you need to explicitly select which method you want to use:

- `Use flat tax rate` - it uses Saleor build-in [tax flow](/developer/taxes#flat-rates)
- `Use app: AvaTax` - if you have installed [AvaTax app](/developer/app-store/apps/avatax/overview) in your dashboard

## Configure AvaTax App

1. Go to AvaTax app details
   ![A screenshot of the Saleor Dashboard in the "Apps" section. The main area displays "Installed Apps," highlighting "AvaTax" with its logo and a link to the app's page.](/docs/developer/app-store/apps/avatax/assets/avatax-app-1.jpg)
2. Configure your first provider by clicking button `Add first provider` and select AvaTax
   ![A screenshot of the Saleor Dashboard in the "AvaTax" app configuration section. The "Add first provider" button is highlighted."](/docs/developer/app-store/apps/avatax/assets/avatax-app-2.jpg)
3. Fill out the form based on values you previously noted down. You can see table below to old and new settings mappings:

| Old setting              | New setting       |
| ------------------------ | ----------------- |
| username or account      | username          |
| company name             | company code      |
| use sandbox              | use sandbox mode  |
| autocommit               | autocommit        |
| shipping tax code        | shipping tax code |
| ship from - street       | address - street  |
| ship from - city         | address - city    |
| ship from - country area | address - state   |
| ship from - country      | address - country |
| ship from - postal code  | address - zip     |

4. The last setting is to select which provider use for which channel. Select previously created provider for those channels you want to use AvaTax app for.
   ![A screenshot of the Saleor Dashboard in the "AvaTax" app section.The main area displays "Available channels," indicating that the table shows channels configured to use the AvaTax app for tax calculations.](/docs/developer/app-store/apps/avatax/assets/avatax-app-3.jpg)

That is it! You are ready to start collecting taxes using AvaTax app.
