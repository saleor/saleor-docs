This guide takes you from installing Saleor MCP to your assistant's first query. You need a Saleor Cloud environment on Saleor 3.23 or later. Steps 2 and 3 need an administrator: a staff user with both `MANAGE_APPS` and `MANAGE_STAFF`.

## 1. Get the App

Saleor MCP may already be installed. Check **Extensions → Installed** in the Saleor Dashboard.

If it isn't there, install it from **Extensions → Explore**, or find it on [apps.saleor.io](https://apps.saleor.io).

## 2. Set App Permissions

App permissions are the most Saleor MCP can reach for anyone in the environment.

1. Open **Saleor MCP → Settings**.
2. Under **App permissions**, choose the areas Saleor MCP may reach, then select **Review changes** and approve them in Saleor.

The app also needs `MANAGE_STAFF` to read your permission groups for the group policy.

## 3. Grant Access to Permission Groups

A permission group with no assignment gets no access through Saleor MCP.

1. In **Saleor MCP → Settings → Group policy**, pick a permission group.
2. For each area, choose **None**, **Read**, **Edit**, or **Full**.
3. Save.

Start with **Read** to try things out. See [Permissions and Mutation Tiers](/developer/app-store/apps/mcp/permissions) for what each level allows.

## 4. Connect a Client

Open **Saleor MCP → Connect** and pick your client. The Connect page shows the setup for your environment, with the right MCP URL already filled in. Always copy the command or snippet from the Connect page. Don't type the MCP URL by hand.

<Tabs>
<Tab title="Codex">

Copy the command from the Connect page and run it. It looks like this:

```shell
codex mcp add saleor --url '<MCP URL from the Connect page>'
```

Then sign in:

```shell
codex mcp login saleor
```

See the [Codex MCP docs](https://developers.openai.com/codex/mcp) for more.

</Tab>
<Tab title="Claude Code">

Copy the command from the Connect page and run it. It looks like this:

```shell
claude mcp add --transport http --scope user saleor \
  '<MCP URL from the Connect page>'
```

Then run `/mcp` in Claude Code and sign in.

See the [Claude Code MCP docs](https://code.claude.com/docs/en/mcp) for more.

</Tab>
<Tab title="Other clients">

Copy the JSON entry from the Connect page into any client that supports remote MCP servers over Streamable HTTP with OAuth. It looks like this:

```json
{
  "mcpServers": {
    "saleor": {
      "type": "http",
      "url": "<MCP URL from the Connect page>"
    }
  }
}
```

Then sign in from the client.

</Tab>
</Tabs>

When you sign in, your client opens a browser. Sign in with your Saleor Cloud account and approve the access the assistant may use. You can lower any area before you approve.

For agents that run without a person signed in, use an [access key](/developer/app-store/apps/mcp/authentication#access-keys) instead.

## 5. Try It

Ask your assistant:

```text
Call connection_info and tell me what you can do in Saleor.
```

Then ask a question about your store, for example:

```text
List the five most recently created products.
```

Many clients also offer the `explore_saleor` prompt. It walks the assistant through looking up the schema and running queries.

To check what the assistant did, an administrator can open **Saleor MCP → Activity**.
