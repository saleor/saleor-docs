<Callout type="info">

Saleor MCP is available only on Saleor Cloud, with Saleor **3.23** or later. Find it in **Dashboard → Extensions**.

</Callout>

Saleor MCP is a hosted Saleor App that lets AI assistants and agents read and change data in your Saleor Cloud environment. It connects them to Saleor's GraphQL API through the [Model Context Protocol](https://modelcontextprotocol.io) (MCP), within the access you allow.

Saleor MCP has no fixed list of commerce actions. Its tools let the assistant look up the schema and run GraphQL. The assistant works in three steps:

1. `connection_info`: who am I, and what am I allowed to do?
2. `introspect_schema`: which operations, arguments, and fields exist?
3. `run_query`, `run_mutation`, or `run_high_impact_mutation`: run the operation and read the GraphQL response.

## Features

- **Two ways to connect.** Staff connect their AI assistant with their own Saleor Cloud login (OAuth). Agents and automations that run on their own use an access key created in the Dashboard. See [Authentication](/developer/app-store/apps/mcp/authentication).
- **Permission-aware.** An assistant never gets more than the app permissions, the user's own Saleor permissions, and the app's group policy allow. See [Permissions and Mutation Tiers](/developer/app-store/apps/mcp/permissions).
- **Reviewed mutations only.** Saleor MCP runs only mutations that Saleor has reviewed. Everyday changes and high-impact changes use separate tools, so your MCP client asks for approval separately.
- **Activity log.** Every tool call appears in the app's **Activity** tab, so staff with `MANAGE_APPS` and `MANAGE_STAFF` can see who did what.
- **No Saleor tokens in clients.** MCP clients never receive a Saleor token.

## Limitations

Some areas can't be changed through Saleor MCP, such as staff, apps, webhooks, customers, checkouts, metadata, channels, and shop settings. Use the Saleor Dashboard for those. See [Mutation tiers](/developer/app-store/apps/mcp/permissions#mutation-tiers).
