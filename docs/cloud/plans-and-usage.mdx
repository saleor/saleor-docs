Cloud plans combine a subscription, included GMV and fair API usage. Choose monthly payment or an annual prepaid subscription. [Saleor pricing](https://saleor.io/pricing) lists current prices and inclusions; this guide explains how the allowances and payment options work.

## Monthly Payment

Volume illustrates the three available combinations:

| Option                                | Upfront | During development | First 12 months after go-live |
| ------------------------------------- | ------: | -----------------: | ----------------------------: |
| Cloud                                 |      $0 |       $3,999/month |                  $3,999/month |
| Cloud + Accelerator                   |  $6,000 |           $0/month |                  $3,499/month |
| Cloud + Accelerator + Made-to-Measure | $18,000 |           $0/month |                  $2,499/month |

Accelerator provides fully supported Cloud during development, with subscription billing starting at go-live. Made-to-Measure adds delivery work by Saleor’s engineers and requires Accelerator. Cloud alone requires neither upfront option.

On Volume, Accelerator’s $6,000 fee returns as $500/month in subscription credits for 12 months after go-live. Adding Made-to-Measure brings the upfront total to $18,000 and credits to $1,500/month. All three options are $3,999/month after the credit period. Usage overages are additional.

Select includes a smaller Made-to-Measure engagement; Enterprise engagements are custom. Across plans, 100% of Accelerator and Made-to-Measure fees return as subscription credits over the first year after go-live. Saleor agrees the work with you rather than selling development hours.

## Annual Payment

| Plan       | Annual payment | Annual GMV allowance | Monthly High Tide allowance |
| ---------- | -------------: | -------------------: | --------------------------: |
| Select     |        $15,990 |                $2.4M |                    $600,000 |
| Volume     |        $39,990 |                 $12M |                         $3M |
| Enterprise |         Custom |     Contract-defined |            Contract-defined |

Select and Volume provide twelve months for ten months’ subscription price. Accelerator and Made-to-Measure are included without separate upfront fees. Payment is upfront; the subscription year begins at go-live. Fully supported Cloud is available during development.

Enterprise agreements can follow the same structure with custom prices and allowances.

## High Tide

High Tide applies only to annual payment. It lets you use up to three times the plan’s normal monthly GMV and API allowances in a month, within the purchased annual allowances. The subscription year runs from go-live, not January to December.

On Volume, up to $3M GMV in a month can draw from the $12M annual allowance without overage. Once the annual allowance is exhausted, further usage incurs the plan’s overage rate.

### Usage Above the Monthly Burst Allowance

At $3.5M GMV in one month on Volume:

- $3M counts against the annual allowance.
- $500,000 is billed separately at 0.4%, costing $2,000.
- The separately paid $500,000 does not reduce the annual allowance.

API usage follows the same rule: calls above the monthly burst allowance are billed separately and excluded from annual consumption. This avoids charging twice for the same usage.

### Expiry and Upgrades

Unused annual GMV and API allowances expire at the end of the subscription year, without rollover. An upgrade starts a new contract term. There is no automatic credit for the previous agreement; any credit is negotiated.

## Fair API Usage

API entitlement is based on GMV you have purchased, through your contract or paid overage, rather than actual sales alone. The default ratio is 50 API calls per $1 of purchased GMV on Select and Volume. Custom agreements can specify a different ratio, including when GMV pricing is discounted.

For example, Volume’s $12M annual GMV allowance provides 600M API calls at the standard ratio, even if actual GMV is lower. The monthly equivalent is 50M calls; High Tide permits up to 150M calls in a month within the available annual allowance.

| Plan       | Standard excess API charge |
| ---------- | -------------------------: |
| Select     |      $0.16 per 1,000 calls |
| Volume     |      $0.08 per 1,000 calls |
| Enterprise |           Contract-defined |

Buying GMV overage also adds API entitlement at the applicable ratio. For example, $500,000 of purchased GMV overage provides 25M calls at 50 calls per dollar. The dollar in this calculation is the GMV purchased, not the fee paid for the overage.

Engine usage also draws down the API usage entitlement. See [Engine hosting economics](/cloud/engine#usage-and-hosting-economics) when comparing Engine with external hosting.
