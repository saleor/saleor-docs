Saleor Cloud is the managed Saleor system: the commerce core, Engine, Pulse, Essential Apps and support. Saleor runs the infrastructure; your team owns its storefront and integration code. Use this guide to evaluate Cloud, then follow the technical guides for your implementation.

## What Does Cloud Include?

| Component      | What it provides                                                                                                                                              |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Commerce core  | Saleor’s GraphQL API, Dashboard and commerce data, with managed infrastructure, scaling, updates and backups.                                                 |
| Engine         | Hosting for storefronts, apps, integration code, jobs and agents alongside the core. Available in open beta.                                                  |
| Essential Apps | Saleor-operated capabilities including customer emails, payments, feeds and AI integrations. See [available integrations](/developer/app-store/integrations). |
| Pulse          | Revenue, orders, returns and low-stock information in the Dashboard.                                                                                          |
| Support        | Technical support and delivery guidance for your team. See the current plan inclusions on [pricing](https://saleor.io/pricing).                               |

Select, Volume and Enterprise include these parts of Cloud. Accelerator and Made-to-Measure are optional with monthly payment and included with annual payment; see [plans and usage](/cloud/plans-and-usage).

## Storefronts and Integrations

Start with [Paper](/developer/storefront/paper), Saleor’s open-source Next.js storefront, or connect your own frontend to Saleor’s API. Your team or Saleor’s engineers through Made-to-Measure can adapt Paper. Engine can host Paper, a storefront your team builds in another stack, and custom integration code.

Connect ERP, inventory, fulfillment and other services through GraphQL and webhooks. Keep custom code separate from the commerce core so you can upgrade Saleor without maintaining a fork. Read the [extension guide](/developer/extending/overview).

## Who Builds and Runs Each Part?

| Work                                      | Responsibility                                                                                      |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------- |
| Operate Saleor Cloud infrastructure       | Saleor manages the hosted core and Cloud services.                                                  |
| Build storefronts and custom integrations | Your developers or agency, with optional Made-to-Measure delivery from Saleor’s engineers.          |
| Host custom code                          | Use Engine or arrange external hosting. See [Engine and application hosting](/cloud/engine).        |
| Store custom application state            | Use Saleor’s API and dynamic modelling where suitable, or connect to an external database or cache. |
| Maintain custom implementation code       | Your team or agency owns the code after handover; Cloud support continues through your plan.        |

## Choose How to Start

- **Explore:** create a free development sandbox and follow the [Cloud quickstart](/quickstart/cloud).
- **Build on monthly Cloud:** pay the subscription from the start, with no upfront add-ons required.
- **Use Accelerator:** pay upfront for fully supported Cloud during development; subscription billing starts at go-live.
- **Add Made-to-Measure:** work with Saleor’s engineers on Paper adaptations, integrations and custom features. Requires Accelerator.
- **Pay annually:** Accelerator and Made-to-Measure are included, with the paid subscription year starting at go-live.

The [plans and usage guide](/cloud/plans-and-usage) explains payment, subscription credits, High Tide and API allowances. The [pricing page](https://saleor.io/pricing) is the commercial reference for current prices.

## Ownership and Hosting Choice

You own your data and custom code. Cloud includes managed services that you must replace or operate yourself if you move to self-hosting. Read [Cloud vs Self-Hosting](/cloud/saas-self-host) before choosing a deployment model.
