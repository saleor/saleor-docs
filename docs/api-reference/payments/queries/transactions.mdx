List of transactions. For apps with `MANAGE_ORDERS` permission, returns all transactions. For apps with just `HANDLE_PAYMENTS` permission, returns only transactions created by that app. For staff users, returns transactions from orders and checkouts in channels they have access to.

<Badge variant="accent">Added in Saleor 3.22</Badge>



<Permissions label="Requires one of the following permissions" values="HANDLE_PAYMENTS,MANAGE_ORDERS" />





```graphql
transactions(where: TransactionWhereInput, sortBy: TransactionSortingInput, before: String, after: String, first: Int, last: Int): TransactionCountableConnection
```
