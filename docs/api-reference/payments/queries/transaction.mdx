Look up a transaction by ID.



<Permissions label="Requires one of the following permissions" values="HANDLE_PAYMENTS,MANAGE_ORDERS" />





```graphql
transaction(id: ID, token: UUID): TransactionItem
```

## Arguments

### id [#id]

**`id`** · [`ID`](/api-reference/miscellaneous/scalars/id)

ID of a transaction. Either it or token is required to fetch the transaction data.

### token [#token]

**`token`** · [`UUID`](/api-reference/miscellaneous/scalars/uuid)

Token of a transaction. Either it or ID is required to fetch the transaction data.
