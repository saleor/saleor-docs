Fields required to check a payment balance.

The legacy Payments API is deprecated and will be removed. Use the Transactions API instead.



```graphql
input PaymentCheckBalanceInput {
  gatewayId: String!
  method: String!
  channel: String!
  card: CardInput!
}
```


## Fields

### gatewayId [#gateway-id]

**`gatewayId`** · [`String!`](/api-reference/miscellaneous/scalars/string)

An ID of a payment gateway to check.
### method [#method]

**`method`** · [`String!`](/api-reference/miscellaneous/scalars/string)

Payment method name.
### channel [#channel]

**`channel`** · [`String!`](/api-reference/miscellaneous/scalars/string)

Slug of a channel for which the data should be returned.
### card [#card]

**`card`** · [`CardInput!`](/api-reference/miscellaneous/inputs/card-input)

Information about card.
