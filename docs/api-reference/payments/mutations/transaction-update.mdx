Update transaction.

Requires the following permissions: OWNER and HANDLE_PAYMENTS for apps, HANDLE_PAYMENTS for staff users. Staff user cannot update a transaction that is owned by the app.



```graphql
transactionUpdate(id: ID, token: UUID, transaction: TransactionUpdateInput, transactionEvent: TransactionEventInput): TransactionUpdate
```

## Arguments

### id [#id]

**`id`** · [`ID`](/api-reference/miscellaneous/scalars/id)

The ID of the transaction. One of field id or token is required.

### token [#token]

**`token`** · [`UUID`](/api-reference/miscellaneous/scalars/uuid)

The token of the transaction. One of field id or token is required.

### transaction [#transaction]

**`transaction`** · [`TransactionUpdateInput`](/api-reference/payments/inputs/transaction-update-input)

Input data required to create a new transaction object.

### transactionEvent [#transaction-event]

**`transactionEvent`** · [`TransactionEventInput`](/api-reference/payments/inputs/transaction-event-input)

Data that defines a transaction transaction.
