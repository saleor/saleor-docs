Request an action for payment transaction. 



<Permissions label="Requires one of the following permissions" values="HANDLE_PAYMENTS" />





```graphql
transactionRequestAction(actionType: TransactionActionEnum!, amount: PositiveDecimal, id: ID, refundReason: String, refundReasonReference: ID, token: UUID): TransactionRequestAction
```

[`TransactionRequestAction`](/api-reference/payments/objects/transaction-request-action)

## Arguments

### actionType [#action-type]

**`actionType`** · [`TransactionActionEnum!`](/api-reference/payments/enums/transaction-action-enum)

Determines the action type.

### amount [#amount]

**`amount`** · [`PositiveDecimal`](/api-reference/miscellaneous/scalars/positive-decimal)

Transaction request amount. If empty, maximal possible amount will be used.

### id [#id]

**`id`** · [`ID`](/api-reference/miscellaneous/scalars/id)

The ID of the transaction. One of field id or token is required.

### refundReason [#refund-reason]

**`refundReason`** · [`String`](/api-reference/miscellaneous/scalars/string)

Reason of the refund

<Badge variant="accent">Added in Saleor 3.22</Badge>

### refundReasonReference [#refund-reason-reference]

**`refundReasonReference`** · [`ID`](/api-reference/miscellaneous/scalars/id)

ID of a `Page` (Model) to reference in reason.

<Badge variant="accent">Added in Saleor 3.22</Badge>

### token [#token]

**`token`** · [`UUID`](/api-reference/miscellaneous/scalars/uuid)

The token of the transaction. One of field id or token is required.
