Tokenize payment method. 



<Permissions label="Requires one of the following permissions" values="AUTHENTICATED_USER" />



Triggers the following webhook events:
- PAYMENT_METHOD_PROCESS_TOKENIZATION_SESSION (sync): The customer continues payment method tokenization.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [], syncEvents: [PAYMENT_METHOD_PROCESS_TOKENIZATION_SESSION])
```



```graphql
paymentMethodProcessTokenization(channel: String!, data: JSON, id: String!): PaymentMethodProcessTokenization
```

## Arguments

### channel [#channel]

**`channel`** · [`String!`](/api-reference/miscellaneous/scalars/string)

Slug of a channel related to tokenization request.

### data [#data]

**`data`** · [`JSON`](/api-reference/miscellaneous/scalars/json)

The data that will be passed to the payment gateway.

### id [#id]

**`id`** · [`String!`](/api-reference/miscellaneous/scalars/string)
