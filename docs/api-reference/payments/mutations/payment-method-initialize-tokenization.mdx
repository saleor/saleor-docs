Tokenize payment method. 



<Permissions label="Requires one of the following permissions" values="AUTHENTICATED_USER" />



Triggers the following webhook events:
- PAYMENT_METHOD_INITIALIZE_TOKENIZATION_SESSION (sync): The customer requested to tokenize payment method.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [], syncEvents: [PAYMENT_METHOD_INITIALIZE_TOKENIZATION_SESSION])
```



```graphql
paymentMethodInitializeTokenization(channel: String!, data: JSON, id: String!, paymentFlowToSupport: TokenizedPaymentFlowEnum!): PaymentMethodInitializeTokenization
```

## Arguments

### channel [#channel]

**`channel`** · [`String!`](/api-reference/miscellaneous/scalars/string)

Slug of a channel related to tokenization request.

### data [#data]

**`data`** · [`JSON`](/api-reference/miscellaneous/scalars/json)

### id [#id]

**`id`** · [`String!`](/api-reference/miscellaneous/scalars/string)

The identifier of the payment gateway app to initialize payment method tokenization.

**`paymentFlowToSupport`** · [`TokenizedPaymentFlowEnum!`](/api-reference/payments/enums/tokenized-payment-flow-enum)

The payment flow that the tokenized payment method should support.
