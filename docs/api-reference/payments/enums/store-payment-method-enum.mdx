Enum representing the type of a payment storage in a gateway.



```graphql
enum StorePaymentMethodEnum {
  ON_SESSION @deprecated(reason: "The legacy Payments API is deprecated and will be removed. Use the Transactions API instead.")
  OFF_SESSION @deprecated(reason: "The legacy Payments API is deprecated and will be removed. Use the Transactions API instead.")
  NONE @deprecated(reason: "The legacy Payments API is deprecated and will be removed. Use the Transactions API instead.")
}
```


## Values

### ON_SESSION [#on-session]

`ON_SESSION`

On session storage type. The payment is stored only to be reused when the customer is present in the checkout flow.

:::warning[Deprecated]
The legacy Payments API is deprecated and will be removed. Use the Transactions API instead.
:::


### OFF_SESSION [#off-session]

`OFF_SESSION`

Off session storage type. The payment is stored to be reused even if the customer is absent.

:::warning[Deprecated]
The legacy Payments API is deprecated and will be removed. Use the Transactions API instead.
:::


### NONE [#none]

`NONE`

Storage is disabled. The payment is not stored.

:::warning[Deprecated]
The legacy Payments API is deprecated and will be removed. Use the Transactions API instead.
:::
