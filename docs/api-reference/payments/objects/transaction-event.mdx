Represents transaction's event.



```graphql
type TransactionEvent implements Node {
  id: ID!
  createdAt: DateTime!
  pspReference: String!
  message: String!
  reasonReference: Page
  externalUrl: String!
  amount: Money!
  type: TransactionEventTypeEnum
  createdBy: UserOrApp
  idempotencyKey: String
}
```
