An object representing a single payment.

The legacy Payments API is deprecated and will be removed. Use the Transactions API instead.



```graphql
type Transaction implements Node {
  id: ID!
  created: DateTime!
  payment: Payment!
  token: String!
  kind: TransactionKind!
  isSuccess: Boolean!
  error: String
  gatewayResponse: JSONString! @deprecated(reason: "The legacy Payments API is deprecated and will be removed. Use the Transactions API instead.")
  amount: Money
}
```
