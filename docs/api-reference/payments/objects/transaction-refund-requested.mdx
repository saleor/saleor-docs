Event sent when transaction refund is requested.



```graphql
type TransactionRefundRequested implements Event {
  issuedAt: DateTime
  version: String
  issuingPrincipal: IssuingPrincipal
  recipient: App
  transaction: TransactionItem
  action: TransactionAction!
  idempotencyKey: String!
  grantedRefund: OrderGrantedRefund
}
```

**`action`** · [`TransactionAction!`](/api-reference/payments/objects/transaction-action)

### idempotencyKey [#idempotency-key]

**`idempotencyKey`** · [`String!`](/api-reference/miscellaneous/scalars/string)

Idempotency key assigned to this requested action. Saleor's delivery retries of this request carry the same key, so an app can use it to avoid performing the action twice. Requesting the action again is a new request and gets a new key.

<Badge variant="accent">Added in Saleor 3.23</Badge>
