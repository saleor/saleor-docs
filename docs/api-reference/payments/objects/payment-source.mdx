Represents a payment source stored for user in payment gateway, such as credit card.

The legacy Payments API is deprecated and will be removed. Use the Transactions API instead.



```graphql
type PaymentSource {
  gateway: String!
  paymentMethodId: String
  creditCardInfo: CreditCard
  metadata: [MetadataItem!]!
}
```


## Fields

### gateway [#gateway]

**`gateway`** · [`String!`](/api-reference/miscellaneous/scalars/string)

Payment gateway name.
### paymentMethodId [#payment-method-id]

**`paymentMethodId`** · [`String`](/api-reference/miscellaneous/scalars/string)

ID of stored payment method.
### creditCardInfo [#credit-card-info]

**`creditCardInfo`** · [`CreditCard`](/api-reference/payments/objects/credit-card)

Stored credit card details if available.
### metadata [#metadata]

**`metadata`** · [`[MetadataItem!]!`](/api-reference/miscellaneous/objects/metadata-item)

List of public metadata items.

Can be accessed without permissions.
