Customer-facing summary of a single payment transaction. Exposes the payment method and the amounts, without the identifiers, events and actions available on `TransactionItem`.

<Badge
  text="Added in Saleor 3.23"
  class="badge badge--secondary margin-bottom--sm"
/>

```graphql
type TransactionSummary {
  createdAt: DateTime!
  paymentMethodDetails: PaymentMethodDetails
  authorizedAmount: Money!
  authorizePendingAmount: Money!
  chargedAmount: Money!
  chargePendingAmount: Money!
  refundedAmount: Money!
  canceledAmount: Money!
}
```

### Fields

#### [<code>createdAt</code>](#created-at)<Bullet />[<code>DateTime!</code>](/api-reference/miscellaneous/scalars/date-time.mdx) \{#created-at\}

Date and time at which payment transaction was created.

#### [<code>paymentMethodDetails</code>](#payment-method-details)<Bullet />[<code>PaymentMethodDetails</code>](/api-reference/miscellaneous/interfaces/payment-method-details.mdx) \{#payment-method-details\}

The payment method used for this transaction. As this field is public, card number digits and expiration date are stripped: `firstDigits`, `lastDigits`, `expMonth` and `expYear` of `CardPaymentMethodDetails` are always `null` here. Read them through `Order.transactions` instead, which requires MANAGE_ORDERS or HANDLE_PAYMENTS.

#### [<code>authorizedAmount</code>](#authorized-amount)<Bullet />[<code>Money!</code>](/api-reference/miscellaneous/objects/money.mdx) \{#authorized-amount\}

Total amount authorized for this payment.

#### [<code>authorizePendingAmount</code>](#authorize-pending-amount)<Bullet />[<code>Money!</code>](/api-reference/miscellaneous/objects/money.mdx) \{#authorize-pending-amount\}

Total amount of ongoing authorization requests for the transaction.

#### [<code>chargedAmount</code>](#charged-amount)<Bullet />[<code>Money!</code>](/api-reference/miscellaneous/objects/money.mdx) \{#charged-amount\}

Total amount charged for this payment.

#### [<code>chargePendingAmount</code>](#charge-pending-amount)<Bullet />[<code>Money!</code>](/api-reference/miscellaneous/objects/money.mdx) \{#charge-pending-amount\}

Total amount of ongoing charge requests for the transaction.

#### [<code>refundedAmount</code>](#refunded-amount)<Bullet />[<code>Money!</code>](/api-reference/miscellaneous/objects/money.mdx) \{#refunded-amount\}

Total amount refunded for this payment.

#### [<code>canceledAmount</code>](#canceled-amount)<Bullet />[<code>Money!</code>](/api-reference/miscellaneous/objects/money.mdx) \{#canceled-amount\}
