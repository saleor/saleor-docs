Tokenize payment method. 



<Permissions label="Requires one of the following permissions" values="AUTHENTICATED_USER" />



Triggers the following webhook events:
- PAYMENT_METHOD_PROCESS_TOKENIZATION_SESSION (sync): The customer continues payment method tokenization.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [], syncEvents: [PAYMENT_METHOD_PROCESS_TOKENIZATION_SESSION])
```
