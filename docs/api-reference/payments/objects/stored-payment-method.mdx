Represents a payment method stored for user (tokenized) in payment gateway.



```graphql
type StoredPaymentMethod {
  id: ID!
  gateway: PaymentGateway!
  paymentMethodId: String!
  creditCardInfo: CreditCard
  supportedPaymentFlows: [TokenizedPaymentFlowEnum!]
  type: String!
  name: String
  data: JSON
}
```


## Fields

### id [#id]

**`id`** · [`ID!`](/api-reference/miscellaneous/scalars/id)

Stored payment method ID.
### gateway [#gateway]

**`gateway`** · [`PaymentGateway!`](/api-reference/payments/objects/payment-gateway)

Payment gateway that stores this payment method.
### paymentMethodId [#payment-method-id]

**`paymentMethodId`** · [`String!`](/api-reference/miscellaneous/scalars/string)

ID of stored payment method used to make payment actions. Note: method ID is unique only within the payment gateway.
### creditCardInfo [#credit-card-info]

**`creditCardInfo`** · [`CreditCard`](/api-reference/payments/objects/credit-card)

Stored credit card details if available.
### supportedPaymentFlows [#supported-payment-flows]

**`supportedPaymentFlows`** · [`[TokenizedPaymentFlowEnum!]`](/api-reference/payments/enums/tokenized-payment-flow-enum)


### type [#type]

**`type`** · [`String!`](/api-reference/miscellaneous/scalars/string)

Type of the payment method. Example: credit card, wallet, etc.
### name [#name]

**`name`** · [`String`](/api-reference/miscellaneous/scalars/string)

Payment method name. Example: last 4 digits of credit card, obfuscated email, etc.
### data [#data]

**`data`** · [`JSON`](/api-reference/miscellaneous/scalars/json)

JSON data returned by Payment Provider app for this payment method.
