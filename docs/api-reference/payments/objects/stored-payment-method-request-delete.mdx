Request to delete a stored payment method on payment provider side. 



<Permissions label="Requires one of the following permissions" values="AUTHENTICATED_USER" />



Triggers the following webhook events:
- STORED_PAYMENT_METHOD_DELETE_REQUESTED (sync): The customer requested to delete a payment method.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [], syncEvents: [STORED_PAYMENT_METHOD_DELETE_REQUESTED])
```
