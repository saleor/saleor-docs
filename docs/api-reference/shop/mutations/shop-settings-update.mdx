Updates shop settings. 



<Permissions label="Requires one of the following permissions" values="MANAGE_SETTINGS" />



Triggers the following webhook events:
- SHOP_METADATA_UPDATED (async): Optionally triggered when public or private metadata is updated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [SHOP_METADATA_UPDATED], syncEvents: [])
```



```graphql
shopSettingsUpdate(input: ShopSettingsInput!): ShopSettingsUpdate
```
