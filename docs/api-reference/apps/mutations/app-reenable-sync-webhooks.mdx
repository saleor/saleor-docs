Re-enable sync webhooks for provided app. Can be used to manually re-enable sync webhooks for the app before the cooldown period ends.

Added in Saleor 3.21. 



<Permissions label="Requires one of the following permissions" values="MANAGE_APPS" />





```graphql
appReenableSyncWebhooks(appId: ID!): AppReenableSyncWebhooks
```
