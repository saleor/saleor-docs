Retry failed installation of new app. 



<Permissions label="Requires one of the following permissions" values="MANAGE_APPS" />



Triggers the following webhook events:
- APP_INSTALLED (async): An app was installed.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [APP_INSTALLED], syncEvents: [])
```



```graphql
appRetryInstall(activateAfterInstallation: Boolean = true, id: ID!): AppRetryInstall
```

## Arguments

### activateAfterInstallation [#activate-after-installation]

**`activateAfterInstallation`** · [`Boolean`](/api-reference/miscellaneous/scalars/boolean)

Determine if app will be set active or not.

Default: `true`.

### id [#id]

**`id`** · [`ID!`](/api-reference/miscellaneous/scalars/id)

ID of failed installation.
