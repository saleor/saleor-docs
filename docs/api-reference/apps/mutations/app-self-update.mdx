Updates the app that calls this mutation. Only the app itself can change these fields - staff users cannot set them via `appUpdate`.

Added in Saleor 3.23. 



<Permissions label="Requires one of the following permissions" values="AUTHENTICATED_APP" />





```graphql
appSelfUpdate(input: AppSelfUpdateInput!): AppSelfUpdate
```
