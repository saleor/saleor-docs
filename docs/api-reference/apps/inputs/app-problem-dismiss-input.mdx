Input for dismissing app problems. Only one can be specified.



```graphql
input AppProblemDismissInput {
  byApp: AppProblemDismissByAppInput
  byStaffWithIds: AppProblemDismissByStaffWithIdsInput
  byStaffWithKeys: AppProblemDismissByStaffWithKeysInput
}
```


## Fields

### byApp [#by-app]

**`byApp`** · [`AppProblemDismissByAppInput`](/api-reference/apps/inputs/app-problem-dismiss-by-app-input)

For app callers only - dismiss own problems.
### byStaffWithIds [#by-staff-with-ids]

**`byStaffWithIds`** · [`AppProblemDismissByStaffWithIdsInput`](/api-reference/apps/inputs/app-problem-dismiss-by-staff-with-ids-input)

For staff callers - dismiss problems by IDs.
### byStaffWithKeys [#by-staff-with-keys]

**`byStaffWithKeys`** · [`AppProblemDismissByStaffWithKeysInput`](/api-reference/apps/inputs/app-problem-dismiss-by-staff-with-keys-input)

For staff callers - dismiss problems by keys for specified app.
