Represents ongoing installation of app.



```graphql
type AppInstallation implements Node & Job {
  id: ID!
  status: JobStatusEnum!
  createdAt: DateTime!
  updatedAt: DateTime!
  message: String
  appName: String!
  manifestUrl: String!
  brand: AppBrand
}
```
