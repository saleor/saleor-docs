Represents app data.



```graphql
type AppExtension implements Node {
  id: ID!
  permissions: [Permission!]!
  label: String!
  url: String!
  mountName: String!
  targetName: String!
  settings: JSON!
  identifier: String
  app: App!
  accessToken: String
}
```


## Interfaces

[`Node`](/api-reference/miscellaneous/interfaces/node)

## Fields

### id [#id]

**`id`** · [`ID!`](/api-reference/miscellaneous/scalars/id)

The ID of the app extension.
### permissions [#permissions]

**`permissions`** · [`[Permission!]!`](/api-reference/authentication/objects/permission)

List of the app extension's permissions.
### label [#label]

**`label`** · [`String!`](/api-reference/miscellaneous/scalars/string)

Label of the extension to show in the dashboard.
### url [#url]

**`url`** · [`String!`](/api-reference/miscellaneous/scalars/string)

URL of a view where extension's iframe is placed.
### mountName [#mount-name]

**`mountName`** · [`String!`](/api-reference/miscellaneous/scalars/string)

Name of the extension mount point in the dashboard. Value returned in UPPERCASE.

<Badge variant="accent">Added in Saleor 3.22</Badge>
### targetName [#target-name]

**`targetName`** · [`String!`](/api-reference/miscellaneous/scalars/string)

Name of the extension target in the dashboard. Value returned in UPPERCASE.

<Badge variant="accent">Added in Saleor 3.22</Badge>
### settings [#settings]

**`settings`** · [`JSON!`](/api-reference/miscellaneous/scalars/json)

App extension settings.

<Badge variant="accent">Added in Saleor 3.22</Badge>
### identifier [#identifier]

**`identifier`** · [`String`](/api-reference/miscellaneous/scalars/string)

Extension identifier, unique per app. Null when the app does not declare one.

<Badge variant="accent">Added in Saleor 3.23</Badge>
### app [#app]

**`app`** · [`App!`](/api-reference/apps/objects/app)

The app assigned to app extension.
### accessToken [#access-token]

**`accessToken`** · [`String`](/api-reference/miscellaneous/scalars/string)

JWT token used to authenticate by third-party app extension.
