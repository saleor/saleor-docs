Represents the app's manifest brand data.

```graphql
type AppManifestBrandLogo {
  default(
    size: Int
    sizeRounding: ThumbnailSizeRoundingEnum = NEAREST
    format: IconThumbnailFormatEnum = ORIGINAL
  ): String!
}
```

### Fields

#### [<code>default</code>](#default)<Bullet />[<code>String!</code>](/api-reference/miscellaneous/scalars/string.mdx) \{#default\}

Data URL with a base64 encoded logo image.

##### [<code>size</code>](#app-manifest-brand-logo-default-size)<Bullet />[<code>Int</code>](/api-reference/miscellaneous/scalars/int.mdx) \{#app-manifest-brand-logo-default-size\}

Desired longest side the image in pixels. Defaults to 4096. Images are never cropped. Pass 0 to retrieve the original size (not recommended). Thumbnails are generated only in the available sizes: 32, 64, 128, 256, 512, 1024, 2048, 4096; `sizeRounding` determines which one is used.

##### [<code>sizeRounding</code>](#app-manifest-brand-logo-default-size-rounding)<Bullet />[<code>ThumbnailSizeRoundingEnum</code>](/api-reference/miscellaneous/enums/thumbnail-size-rounding-enum.mdx) \{#app-manifest-brand-logo-default-size-rounding\}

Determines how the requested size is matched to an available thumbnail size.
