Represents a problem associated with an app.





```graphql
type AppProblem implements Node {
  id: ID!
  createdAt: DateTime!
  updatedAt: DateTime!
  count: Int!
  isCritical: Boolean!
  dismissed: AppProblemDismissed
  message: String!
  key: String!
}
```


## Interfaces

[`Node`](/api-reference/miscellaneous/interfaces/node)

## Fields

### id [#id]

**`id`** · [`ID!`](/api-reference/miscellaneous/scalars/id)

The ID of the app problem.


### createdAt [#created-at]

**`createdAt`** · [`DateTime!`](/api-reference/miscellaneous/scalars/date-time)

The date and time when the problem was created.


### updatedAt [#updated-at]

**`updatedAt`** · [`DateTime!`](/api-reference/miscellaneous/scalars/date-time)

The date and time when the problem was last updated.


### count [#count]

**`count`** · [`Int!`](/api-reference/miscellaneous/scalars/int)

Number of occurrences.


### isCritical [#is-critical]

**`isCritical`** · [`Boolean!`](/api-reference/miscellaneous/scalars/boolean)

Whether the problem has reached critical threshold.


### dismissed [#dismissed]

**`dismissed`** · [`AppProblemDismissed`](/api-reference/miscellaneous/objects/app-problem-dismissed)

Dismissal information. Null if the problem has not been dismissed.

### message [#message]

**`message`** · [`String!`](/api-reference/miscellaneous/scalars/string)

The problem message.


### key [#key]

**`key`** · [`String!`](/api-reference/miscellaneous/scalars/string)

Key identifying the type of problem.
