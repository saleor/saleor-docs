The manifest definition.



```graphql
type Manifest {
  identifier: String!
  version: String!
  name: String!
  about: String
  permissions: [Permission!]
  appUrl: String
  configurationUrl: String @deprecated(reason: "Use `appUrl` instead.")
  tokenTargetUrl: String
  dataPrivacy: String @deprecated(reason: "Use `dataPrivacyUrl` instead.")
  dataPrivacyUrl: String
  deprecationReason: String
  homepageUrl: String
  supportUrl: String
  extensions: [AppManifestExtension!]!
  webhooks: [AppManifestWebhook!]!
  audience: String
  requiredSaleorVersion: AppManifestRequiredSaleorVersion
  author: String
  brand: AppManifestBrand
}
```

### dataPrivacyUrl [#data-privacy-url]

### deprecationReason [#deprecation-reason]

**`deprecationReason`** · [`String`](/api-reference/miscellaneous/scalars/string)

Reason why the app is deprecated, declared in the manifest. Null when the app is not deprecated. A deprecated app can still be installed and works as usual, but usually means it should not be used anymore.

<Badge variant="accent">Added in Saleor 3.23</Badge>
