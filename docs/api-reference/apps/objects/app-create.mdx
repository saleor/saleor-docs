Creates a new app. 

<Permissions label="Requires the following permissions" values="AUTHENTICATED_STAFF_USER,MANAGE_APPS" />



Triggers the following webhook events:
- APP_INSTALLED (async): An app was installed.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [APP_INSTALLED], syncEvents: [])
```
