Deletes an app. 



<Permissions label="Requires one of the following permissions" values="MANAGE_APPS" />



Triggers the following webhook events:
- APP_DELETED (async): An app was deleted.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [APP_DELETED], syncEvents: [])
```
