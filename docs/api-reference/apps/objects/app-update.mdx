Updates an existing app. 



<Permissions label="Requires one of the following permissions" values="MANAGE_APPS" />



Triggers the following webhook events:
- APP_UPDATED (async): An app was updated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [APP_UPDATED], syncEvents: [])
```

type AppUpdate {
