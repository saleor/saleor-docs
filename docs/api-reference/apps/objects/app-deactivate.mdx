Deactivate the app. 



<Permissions label="Requires one of the following permissions" values="MANAGE_APPS" />



Triggers the following webhook events:
- APP_STATUS_CHANGED (async): An app was deactivated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [APP_STATUS_CHANGED], syncEvents: [])
```
