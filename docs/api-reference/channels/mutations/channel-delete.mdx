Deletes a channel. Orders associated with the deleted channel will be moved to the target channel. Checkouts, product availability, and pricing will be removed. 



<Permissions label="Requires one of the following permissions" values="MANAGE_CHANNELS" />



Triggers the following webhook events:
- CHANNEL_DELETED (async): A channel was deleted.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [CHANNEL_DELETED], syncEvents: [])
```



```graphql
channelDelete(id: ID!, input: ChannelDeleteInput): ChannelDelete
```
