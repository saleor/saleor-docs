Deactivate a channel. 



<Permissions label="Requires one of the following permissions" values="MANAGE_CHANNELS" />



Triggers the following webhook events:
- CHANNEL_STATUS_CHANGED (async): A channel was deactivated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [CHANNEL_STATUS_CHANGED], syncEvents: [])
```



```graphql
channelDeactivate(id: ID!): ChannelDeactivate
```
