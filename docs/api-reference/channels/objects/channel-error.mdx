## Fields

### field [#field]

**`field`** · [`String`](/api-reference/miscellaneous/scalars/string)

Name of a field that caused the error. A value of `null` indicates that the error isn't associated with a particular field.
### message [#message]

**`message`** · [`String`](/api-reference/miscellaneous/scalars/string)

The error message.
### code [#code]

**`code`** · [`ChannelErrorCode!`](/api-reference/channels/enums/channel-error-code)

The error code.
### shippingZones [#shipping-zones]

**`shippingZones`** · [`[ID!]`](/api-reference/miscellaneous/scalars/id)

List of shipping zone IDs which causes the error.
### warehouses [#warehouses]

**`warehouses`** · [`[ID!]`](/api-reference/miscellaneous/scalars/id)

List of warehouses IDs which causes the error.
