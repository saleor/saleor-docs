Deletes menu items. 



<Permissions label="Requires one of the following permissions" values="MANAGE_MENUS" />



Triggers the following webhook events:
- MENU_ITEM_DELETED (async): A menu item was deleted.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [MENU_ITEM_DELETED], syncEvents: [])
```
