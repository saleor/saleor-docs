Moves items of menus. 



<Permissions label="Requires one of the following permissions" values="MANAGE_MENUS" />



Triggers the following webhook events:
- MENU_ITEM_UPDATED (async): Optionally triggered when sort order or parent changed for menu item.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [MENU_ITEM_UPDATED], syncEvents: [])
```



```graphql
type MenuItemMove {
  menu: Menu
  menuErrors: [MenuError!]! @deprecated(reason: "Use `errors` field instead.")
  errors: [MenuError!]!
}
```
