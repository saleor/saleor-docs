Deletes menus. 



<Permissions label="Requires one of the following permissions" values="MANAGE_MENUS" />



Triggers the following webhook events:
- MENU_DELETED (async): A menu was deleted.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [MENU_DELETED], syncEvents: [])
```
