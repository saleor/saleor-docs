Updates a menu. 



<Permissions label="Requires one of the following permissions" values="MANAGE_MENUS" />



Triggers the following webhook events:
- MENU_UPDATED (async): A menu was updated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [MENU_UPDATED], syncEvents: [])
```



```graphql
menuUpdate(id: ID!, input: MenuInput!): MenuUpdate
```
