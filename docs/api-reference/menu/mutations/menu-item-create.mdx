Creates a new menu item. 



<Permissions label="Requires one of the following permissions" values="MANAGE_MENUS" />



Triggers the following webhook events:
- MENU_ITEM_CREATED (async): A menu item was created.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [MENU_ITEM_CREATED], syncEvents: [])
```



```graphql
menuItemCreate(input: MenuItemCreateInput!): MenuItemCreate
```

## Arguments

### input [#input]

**`input`** · [`MenuItemCreateInput!`](/api-reference/miscellaneous/inputs/menu-item-create-input)

Fields required to update a menu item. Only one of `url`, `category`, `page`, `collection` is allowed per item.
