Updates a menu item. 



<Permissions label="Requires one of the following permissions" values="MANAGE_MENUS" />



Triggers the following webhook events:
- MENU_ITEM_UPDATED (async): A menu item was updated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [MENU_ITEM_UPDATED], syncEvents: [])
```



```graphql
menuItemUpdate(id: ID!, input: MenuItemInput!): MenuItemUpdate
```

## Arguments

### id [#id]

**`id`** · [`ID!`](/api-reference/miscellaneous/scalars/id)

ID of a menu item to update.

### input [#input]

**`input`** · [`MenuItemInput!`](/api-reference/miscellaneous/inputs/menu-item-input)

Fields required to update a menu item. Only one of `url`, `category`, `page`, `collection` is allowed per item.
