Creates a new Menu. 



<Permissions label="Requires one of the following permissions" values="MANAGE_MENUS" />



Triggers the following webhook events:
- MENU_CREATED (async): A menu was created.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [MENU_CREATED], syncEvents: [])
```



```graphql
menuCreate(input: MenuCreateInput!): MenuCreate
```
