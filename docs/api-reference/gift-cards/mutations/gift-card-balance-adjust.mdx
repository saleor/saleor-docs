Adjust a gift card's balance by a delta. 

Added in Saleor 3.23. 



<Permissions label="Requires one of the following permissions" values="MANAGE_GIFT_CARD" />



Triggers the following webhook events:
- GIFT_CARD_UPDATED (async): A gift card was updated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [GIFT_CARD_UPDATED], syncEvents: [])
```



```graphql
giftCardBalanceAdjust(amount: Decimal!, id: ID!): GiftCardBalanceAdjust
```

## Arguments

### amount [#amount]

**`amount`** · [`Decimal!`](/api-reference/miscellaneous/scalars/decimal)

Signed amount to adjust the current balance by. Positive tops up, negative deducts. A deduction below zero clamps the balance to zero. A top-up above the initial balance raises the initial balance to the new current balance. 

<Badge variant="accent">Added in Saleor 3.23</Badge>

### id [#id]

**`id`** · [`ID!`](/api-reference/miscellaneous/scalars/id)

ID of the gift card to adjust.
