Deletes gift cards. 



<Permissions label="Requires one of the following permissions" values="MANAGE_GIFT_CARD" />



Triggers the following webhook events:
- GIFT_CARD_DELETED (async): A gift card was deleted.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [GIFT_CARD_DELETED], syncEvents: [])
```



```graphql
giftCardBulkDelete(ids: [ID!]!): GiftCardBulkDelete
```
