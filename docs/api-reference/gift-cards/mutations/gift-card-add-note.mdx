Adds note to the gift card. 



<Permissions label="Requires one of the following permissions" values="MANAGE_GIFT_CARD" />



Triggers the following webhook events:
- GIFT_CARD_UPDATED (async): A gift card was updated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [GIFT_CARD_UPDATED], syncEvents: [])
```



```graphql
giftCardAddNote(id: ID!, input: GiftCardAddNoteInput!): GiftCardAddNote
```
