Resend a gift card. 



<Permissions label="Requires one of the following permissions" values="MANAGE_GIFT_CARD" />



Triggers the following webhook events:
- NOTIFY_USER (async): A notification for gift card resend.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [NOTIFY_USER], syncEvents: [])
```



```graphql

```
