Restrict a gift card so only the given customer can use it. 

Added in Saleor 3.23. 



<Permissions label="Requires one of the following permissions" values="MANAGE_GIFT_CARD" />



Triggers the following webhook events:
- GIFT_CARD_UPDATED (async): A gift card was updated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [GIFT_CARD_UPDATED], syncEvents: [])
```



```graphql
giftCardAssignUser(id: ID!, userId: ID!): GiftCardAssignUser
```

## Arguments

### id [#id]

**`id`** · [`ID!`](/api-reference/miscellaneous/scalars/id)

### userId [#user-id]

**`userId`** · [`ID!`](/api-reference/miscellaneous/scalars/id)
