Creates a new gift card. 



<Permissions label="Requires one of the following permissions" values="MANAGE_GIFT_CARD" />



Triggers the following webhook events:
- GIFT_CARD_CREATED (async): A gift card was created.
- NOTIFY_USER (async): A notification for created gift card.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [GIFT_CARD_CREATED, NOTIFY_USER], syncEvents: [])
```



```graphql
giftCardCreate(input: GiftCardCreateInput!): GiftCardCreate
```
