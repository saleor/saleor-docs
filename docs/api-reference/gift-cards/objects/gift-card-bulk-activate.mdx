Activate gift cards. 



<Permissions label="Requires one of the following permissions" values="MANAGE_GIFT_CARD" />



Triggers the following webhook events:
- GIFT_CARD_STATUS_CHANGED (async): A gift card was activated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [GIFT_CARD_STATUS_CHANGED], syncEvents: [])
```
