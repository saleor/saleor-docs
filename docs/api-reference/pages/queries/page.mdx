Look up a page by ID or slug.



```graphql
page(id: ID, slug: String, slugLanguageCode: LanguageCodeEnum, channel: String): Page
```

## Arguments

### id [#id]

**`id`** · [`ID`](/api-reference/miscellaneous/scalars/id)

ID of the page.

### slug [#slug]

**`slug`** · [`String`](/api-reference/miscellaneous/scalars/string)

The slug of the page.

### slugLanguageCode [#slug-language-code]

**`slugLanguageCode`** · [`LanguageCodeEnum`](/api-reference/miscellaneous/enums/language-code-enum)

Language code of the page slug, omit to use primary slug.

<Badge variant="accent">Added in Saleor 3.21</Badge>

### channel [#channel]

**`channel`** · [`String`](/api-reference/miscellaneous/scalars/string)

Slug of a channel for which the data should be returned.

<Badge variant="accent">Added in Saleor 3.22</Badge>
