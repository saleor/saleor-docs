Creates an attribute.

Triggers the following webhook events:
- ATTRIBUTE_CREATED (async): An attribute was created.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [ATTRIBUTE_CREATED], syncEvents: [])
```
