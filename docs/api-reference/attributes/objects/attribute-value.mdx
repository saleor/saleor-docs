Represents a value of an attribute.



```graphql
type AttributeValue implements Node {
  id: ID!
  name: String
  slug: String
  value: String
  translation(languageCode: LanguageCodeEnum!): AttributeValueTranslation
  inputType: AttributeInputTypeEnum
  reference: ID
  file: File
  richText: JSONString
  plainText: String
  boolean: Boolean
  date: Date
  dateTime: DateTime
  externalReference: String
}
```


## Interfaces

[`Node`](/api-reference/miscellaneous/interfaces/node)

## Fields

### id [#id]

**`id`** · [`ID!`](/api-reference/miscellaneous/scalars/id)

The ID of the attribute value.
### name [#name]

**`name`** · [`String`](/api-reference/miscellaneous/scalars/string)

Name of a value displayed in the interface.
### slug [#slug]

**`slug`** · [`String`](/api-reference/miscellaneous/scalars/string)

Internal representation of a value (unique per attribute).
### value [#value]

**`value`** · [`String`](/api-reference/miscellaneous/scalars/string)

Represent value of the attribute value (e.g. color values for swatch attributes).
### translation [#translation]

**`translation`** · [`AttributeValueTranslation`](/api-reference/attributes/objects/attribute-value-translation)

Returns translated attribute value fields for the given language code.

#### languageCode [#attribute-value-translation-language-code]

**`languageCode`** · [`LanguageCodeEnum!`](/api-reference/miscellaneous/enums/language-code-enum)

A language code to return the translation for attribute value.
### inputType [#input-type]

**`inputType`** · [`AttributeInputTypeEnum`](/api-reference/attributes/enums/attribute-input-type-enum)

The input type to use for entering attribute values in the dashboard.
### reference [#reference]

**`reference`** · [`ID`](/api-reference/miscellaneous/scalars/id)

The ID of the referenced object.
### file [#file]

**`file`** · [`File`](/api-reference/miscellaneous/objects/file)

Represents file URL and content type (if attribute value is a file).
### richText [#rich-text]

**`richText`** · [`JSONString`](/api-reference/miscellaneous/scalars/jsonstring)

Represents the text of the attribute value, includes formatting.

Rich text format. For reference see https://editorjs.io/
### plainText [#plain-text]

**`plainText`** · [`String`](/api-reference/miscellaneous/scalars/string)

Represents the text of the attribute value, plain text without formatting.
### boolean [#boolean]

**`boolean`** · [`Boolean`](/api-reference/miscellaneous/scalars/boolean)

Represents the boolean value of the attribute value.
### date [#date]

**`date`** · [`Date`](/api-reference/miscellaneous/scalars/date)

Represents the date value of the attribute value.
### dateTime [#date-time]

**`dateTime`** · [`DateTime`](/api-reference/miscellaneous/scalars/date-time)

Represents the date/time value of the attribute value.
### externalReference [#external-reference]

**`externalReference`** · [`String`](/api-reference/miscellaneous/scalars/string)

External ID of this attribute value.
