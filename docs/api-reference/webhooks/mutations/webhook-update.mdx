Updates a webhook subscription. 



<Permissions label="Requires one of the following permissions" values="MANAGE_APPS,AUTHENTICATED_APP" />





```graphql
webhookUpdate(id: ID, identifier: String, input: WebhookUpdateInput!): WebhookUpdate
```

## Arguments

### id [#id]

**`id`** · [`ID`](/api-reference/miscellaneous/scalars/id)

ID of a webhook to update. Cannot be used together with `identifier`.

### identifier [#identifier]

**`identifier`** · [`String`](/api-reference/miscellaneous/scalars/string)

App-provided identifier of a webhook to update. Identifiers are unique per app only, so this argument is available exclusively to an app referencing its own webhook; staff users must use `id`. Cannot be used together with `id`.

<Badge variant="accent">Added in Saleor 3.23</Badge>

### input [#input]

**`input`** · [`WebhookUpdateInput!`](/api-reference/webhooks/inputs/webhook-update-input)

Fields required to update a webhook.
