Updates the shipping method of the checkout.

Triggers the following webhook events:
- SHIPPING_LIST_METHODS_FOR_CHECKOUT (sync): Triggered when updating the checkout shipping method with the external one.
- CHECKOUT_FILTER_SHIPPING_METHODS (sync): Optionally triggered when cached filtered shipping methods are invalid.
- CHECKOUT_UPDATED (async): A checkout was updated.

:::warning[Deprecated]
Use `checkoutDeliveryMethodUpdate` instead.
:::




**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [CHECKOUT_UPDATED], syncEvents: [SHIPPING_LIST_METHODS_FOR_CHECKOUT, CHECKOUT_FILTER_SHIPPING_METHODS])
```



```graphql
checkoutShippingMethodUpdate(checkoutId: ID, id: ID, shippingMethodId: ID, token: UUID): CheckoutShippingMethodUpdate
```
