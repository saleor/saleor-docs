Deletes a CheckoutLine.

Triggers the following webhook events:
- CHECKOUT_UPDATED (async): A checkout was updated.

:::warning[Deprecated]
Use `checkoutLinesDelete` instead.
:::




**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [CHECKOUT_UPDATED], syncEvents: [])
```



```graphql
checkoutLineDelete(checkoutId: ID, id: ID, lineId: ID, token: UUID): CheckoutLineDelete
```
