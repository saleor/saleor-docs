Adds products, categories, collections to a sale. 



<Permissions label="Requires one of the following permissions" values="MANAGE_DISCOUNTS" />



Triggers the following webhook events:
- SALE_UPDATED (async): A sale was updated.

:::warning[Deprecated]
Use `promotionRuleCreate` and `promotionRuleUpdate` mutations instead.
:::




**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [SALE_UPDATED], syncEvents: [])
```



```graphql
saleCataloguesAdd(id: ID!, input: CatalogueInput!): SaleAddCatalogues
```
