Export voucher codes to csv/xlsx file.

Added in Saleor 3.18. 



<Permissions label="Requires one of the following permissions" values="MANAGE_DISCOUNTS" />



Triggers the following webhook events:
- VOUCHER_CODE_EXPORT_COMPLETED (async): A notification for the exported file.

:::warning[Deprecated]
Export functionality is deprecated and will be removed. All data can be fetched via the GraphQL API and parsed into the desired format by apps or external tools.
:::




**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [VOUCHER_CODE_EXPORT_COMPLETED], syncEvents: [])
```



```graphql
exportVoucherCodes(input: ExportVoucherCodesInput!): ExportVoucherCodes
```
