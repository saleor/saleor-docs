Creates a new sale. 



<Permissions label="Requires one of the following permissions" values="MANAGE_DISCOUNTS" />



Triggers the following webhook events:
- SALE_CREATED (async): A sale was created.

:::warning[Deprecated]
Use `promotionCreate` mutation instead.
:::




**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [SALE_CREATED], syncEvents: [])
```



```graphql
saleCreate(input: SaleInput!): SaleCreate
```
