Look up a sale by ID.



<Permissions label="Requires one of the following permissions" values="MANAGE_DISCOUNTS" />



:::warning[Deprecated]
Use the `promotion` query instead.
:::




```graphql
sale(id: ID!, channel: String): Sale
```
