Initializes payment process when it is required by gateway.

:::warning[Deprecated]
The legacy Payments API is deprecated and will be removed. Use the Transactions API instead.
:::




```graphql
paymentInitialize(channel: String, gateway: String!, paymentData: JSONString): PaymentInitialize
```

## Arguments

### channel [#channel]

**`channel`** · [`String`](/api-reference/miscellaneous/scalars/string)

Slug of a channel for which the data should be returned.

### gateway [#gateway]

**`gateway`** · [`String!`](/api-reference/miscellaneous/scalars/string)

A gateway name used to initialize the payment.

### paymentData [#payment-data]

**`paymentData`** · [`JSONString`](/api-reference/miscellaneous/scalars/jsonstring)

Client-side generated data required to initialize the payment.
