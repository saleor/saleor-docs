Represents status of a staff account.



```graphql
enum StaffMemberStatus {
  ACTIVE
  DEACTIVATED
}
```


## Values

### ACTIVE [#active]

`ACTIVE`

User account has been activated.

### DEACTIVATED [#deactivated]

`DEACTIVATED`

User account has not been activated yet.
