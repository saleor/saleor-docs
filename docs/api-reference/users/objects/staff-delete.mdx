Deletes a staff user. Apps are not allowed to perform this mutation. 



<Permissions label="Requires one of the following permissions" values="MANAGE_STAFF" />



Triggers the following webhook events:
- STAFF_DELETED (async): A staff account was deleted.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [STAFF_DELETED], syncEvents: [])
```



```graphql
type StaffDelete {
  staffErrors: [StaffError!]! @deprecated(reason: "Use `errors` field instead.")
  errors: [StaffError!]!
  user: User
}
```
