## Fields

### field [#field]

**`field`** · [`String`](/api-reference/miscellaneous/scalars/string)

Name of a field that caused the error. A value of `null` indicates that the error isn't associated with a particular field.
### message [#message]

**`message`** · [`String`](/api-reference/miscellaneous/scalars/string)

The error message.
### code [#code]

**`code`** · [`AccountErrorCode!`](/api-reference/users/enums/account-error-code)

The error code.
### addressType [#address-type]

**`addressType`** · [`AddressTypeEnum`](/api-reference/miscellaneous/enums/address-type-enum)

A type of address that causes the error.
### attributes [#attributes]

**`attributes`** · [`[ID!]`](/api-reference/miscellaneous/scalars/id)

List of attributes IDs which causes the error.

<Badge variant="accent">Added in Saleor 3.23</Badge>
### permissions [#permissions]

**`permissions`** · [`[PermissionEnum!]`](/api-reference/users/enums/permission-enum)

List of permissions which causes the error.
### groups [#groups]

**`groups`** · [`[ID!]`](/api-reference/miscellaneous/scalars/id)

List of permission group IDs which cause the error.
### users [#users]

**`users`** · [`[ID!]`](/api-reference/miscellaneous/scalars/id)

List of user IDs which causes the error.
