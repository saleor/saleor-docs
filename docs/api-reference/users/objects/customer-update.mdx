Updates an existing customer. 



<Permissions label="Requires one of the following permissions" values="MANAGE_USERS" />



Triggers the following webhook events:
- CUSTOMER_UPDATED (async): A new customer account was updated.
- CUSTOMER_METADATA_UPDATED (async): Optionally called when customer's metadata was updated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [CUSTOMER_UPDATED, CUSTOMER_METADATA_UPDATED], syncEvents: [])
```
