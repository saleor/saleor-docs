Sends an email with the account removal link for the logged-in user. 



<Permissions label="Requires one of the following permissions" values="AUTHENTICATED_USER" />



Triggers the following webhook events:
- NOTIFY_USER (async): A notification for account delete request.
- ACCOUNT_DELETE_REQUESTED (async): An account delete requested.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [NOTIFY_USER, ACCOUNT_DELETE_REQUESTED], syncEvents: [])
```
