Represents a type of customer. It allows to segment users and defines what attributes are available to users of this type.

<Badge variant="accent">Added in Saleor 3.23</Badge>



```graphql
type CustomerType implements Node & ObjectWithMetadata {
  id: ID!
  privateMetadata: [MetadataItem!]!
  privateMetafield(key: String!): String
  privateMetafields(keys: [String!]): Metadata
  metadata: [MetadataItem!]!
  metafield(key: String!): String
  metafields(keys: [String!]): Metadata
  name: String!
  slug: String!
  isDefault: Boolean!
  attributes: [Attribute!]
  availableAttributes(where: AttributeWhereInput, search: String, before: String, after: String, first: Int, last: Int): AttributeCountableConnection
}
```
