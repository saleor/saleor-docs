Fields required to create a user.



```graphql
input AccountRegisterInput {
  firstName: String
  lastName: String
  languageCode: LanguageCodeEnum
  email: String!
  password: String!
  redirectUrl: String
  metadata: [MetadataInput!]
  channel: String
}
```


## Fields

### firstName [#first-name]

**`firstName`** · [`String`](/api-reference/miscellaneous/scalars/string)

Given name.
### lastName [#last-name]

**`lastName`** · [`String`](/api-reference/miscellaneous/scalars/string)

Family name.
### languageCode [#language-code]

**`languageCode`** · [`LanguageCodeEnum`](/api-reference/miscellaneous/enums/language-code-enum)

User language code.
### email [#email]

**`email`** · [`String!`](/api-reference/miscellaneous/scalars/string)

The email address of the user.
### password [#password]

**`password`** · [`String!`](/api-reference/miscellaneous/scalars/string)

Password.
### redirectUrl [#redirect-url]

**`redirectUrl`** · [`String`](/api-reference/miscellaneous/scalars/string)

Base of frontend URL that will be needed to create confirmation URL. Required when account confirmation is enabled.
### metadata [#metadata]

**`metadata`** · [`[MetadataInput!]`](/api-reference/miscellaneous/inputs/metadata-input)

User public metadata. Can be read by any API client authorized to read the object it's attached to.

Warning: never store sensitive information, including financial data such as credit card details.
### channel [#channel]

**`channel`** · [`String`](/api-reference/miscellaneous/scalars/string)

Slug of a channel which will be used to notify users. Optional when only one channel exists.
