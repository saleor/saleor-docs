Fields required to update a staff user.



```graphql
input StaffUpdateInput {
  firstName: String
  lastName: String
  email: String
  isActive: Boolean
  note: String
  metadata: [MetadataInput!]
  privateMetadata: [MetadataInput!]
  addGroups: [ID!]
  removeGroups: [ID!]
}
```


## Fields

### firstName [#first-name]

Given name.
### lastName [#last-name]

**`lastName`** · [`String`](/api-reference/miscellaneous/scalars/string)

Family name.
### email [#email]

**`email`** · [`String`](/api-reference/miscellaneous/scalars/string)

The unique email address of the user.
### isActive [#is-active]

**`isActive`** · [`Boolean`](/api-reference/miscellaneous/scalars/boolean)

User account is active.
### note [#note]

**`note`** · [`String`](/api-reference/miscellaneous/scalars/string)

A note about the user.
### metadata [#metadata]

**`metadata`** · [`[MetadataInput!]`](/api-reference/miscellaneous/inputs/metadata-input)

Fields required to update the user metadata. Can be read by any API client authorized to read the object it's attached to.

Warning: never store sensitive information, including financial data such as credit card details.
### privateMetadata [#private-metadata]

**`privateMetadata`** · [`[MetadataInput!]`](/api-reference/miscellaneous/inputs/metadata-input)

Fields required to update the user private metadata. Requires permissions to modify and to read the metadata of the object it's attached to.

Warning: never store sensitive information, including financial data such as credit card details.
### addGroups [#add-groups]

**`addGroups`** · [`[ID!]`](/api-reference/miscellaneous/scalars/id)

List of permission group IDs to which user should be assigned.
### removeGroups [#remove-groups]

**`removeGroups`** · [`[ID!]`](/api-reference/miscellaneous/scalars/id)

List of permission group IDs from which user should be unassigned.
