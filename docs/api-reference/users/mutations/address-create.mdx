Creates user address. 



<Permissions label="Requires one of the following permissions" values="MANAGE_USERS" />



Triggers the following webhook events:
- ADDRESS_CREATED (async): A new address was created.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [ADDRESS_CREATED], syncEvents: [])
```



```graphql
addressCreate(input: AddressInput!, userId: ID!): AddressCreate
```
