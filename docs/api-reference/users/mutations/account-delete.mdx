Remove user account. 



<Permissions label="Requires one of the following permissions" values="AUTHENTICATED_USER" />



Triggers the following webhook events:
- ACCOUNT_DELETED (async): Account was deleted.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [ACCOUNT_DELETED], syncEvents: [])
```



```graphql
accountDelete(token: String!): AccountDelete
```

## Arguments

### token [#token]

**`token`** · [`String!`](/api-reference/miscellaneous/scalars/string)

A one-time token required to remove account. Sent by email using AccountRequestDeletion mutation.
