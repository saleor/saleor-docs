Update permission group. Apps are not allowed to perform this mutation. 



<Permissions label="Requires one of the following permissions" values="MANAGE_STAFF" />



Triggers the following webhook events:
- PERMISSION_GROUP_UPDATED (async)



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [PERMISSION_GROUP_UPDATED], syncEvents: [])
```



```graphql

```
