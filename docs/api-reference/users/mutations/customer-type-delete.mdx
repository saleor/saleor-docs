Deletes a customer type. Users of the deleted customer type are reassigned to the default customer type.

Added in Saleor 3.23. 



<Permissions label="Requires one of the following permissions" values="MANAGE_CUSTOMER_TYPES_AND_ATTRIBUTES" />



Triggers the following webhook events:
- CUSTOMER_TYPE_DELETED (async): A customer type was deleted.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [CUSTOMER_TYPE_DELETED], syncEvents: [])
```



```graphql
customerTypeDelete(id: ID!): CustomerTypeDelete
```
