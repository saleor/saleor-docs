Request email change of the logged in user. 



<Permissions label="Requires one of the following permissions" values="AUTHENTICATED_USER" />



Triggers the following webhook events:
- NOTIFY_USER (async): A notification for account email change.
- ACCOUNT_CHANGE_EMAIL_REQUESTED (async): An account email change was requested.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [NOTIFY_USER, ACCOUNT_CHANGE_EMAIL_REQUESTED], syncEvents: [])
```



```graphql
requestEmailChange(channel: String, newEmail: String!, password: String!, redirectUrl: String!): RequestEmailChange
```

## Arguments

### channel [#channel]

**`channel`** · [`String`](/api-reference/miscellaneous/scalars/string)

Slug of a channel which will be used to notify users. Optional when only one channel exists.

### newEmail [#new-email]

**`newEmail`** · [`String!`](/api-reference/miscellaneous/scalars/string)

New user email.

### password [#password]

**`password`** · [`String!`](/api-reference/miscellaneous/scalars/string)

User password.

### redirectUrl [#redirect-url]

**`redirectUrl`** · [`String!`](/api-reference/miscellaneous/scalars/string)

URL of a view where users should be redirected to update the email address. URL in RFC 1808 format.
