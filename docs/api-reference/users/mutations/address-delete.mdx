Deletes an address. 



<Permissions label="Requires one of the following permissions" values="MANAGE_USERS" />



Triggers the following webhook events:
- ADDRESS_DELETED (async): An address was deleted.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [ADDRESS_DELETED], syncEvents: [])
```



```graphql
addressDelete(id: ID!): AddressDelete
```
