Updates a customer type.

Added in Saleor 3.23. 



<Permissions label="Requires one of the following permissions" values="MANAGE_CUSTOMER_TYPES_AND_ATTRIBUTES" />



Triggers the following webhook events:
- CUSTOMER_TYPE_UPDATED (async): A customer type was updated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [CUSTOMER_TYPE_UPDATED], syncEvents: [])
```



```graphql
customerTypeUpdate(id: ID!, input: CustomerTypeUpdateInput!): CustomerTypeUpdate
```
