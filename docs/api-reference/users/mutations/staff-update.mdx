Updates an existing staff user. Apps are not allowed to perform this mutation. 



<Permissions label="Requires one of the following permissions" values="MANAGE_STAFF" />



Triggers the following webhook events:
- STAFF_UPDATED (async): A staff account was updated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [STAFF_UPDATED], syncEvents: [])
```



```graphql
staffUpdate(id: ID!, input: StaffUpdateInput!): StaffUpdate
```
