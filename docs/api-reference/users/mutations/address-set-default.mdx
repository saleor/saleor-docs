Sets a default address for the given user. 



<Permissions label="Requires one of the following permissions" values="MANAGE_USERS" />



Triggers the following webhook events:
- CUSTOMER_UPDATED (async): A customer was updated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [CUSTOMER_UPDATED], syncEvents: [])
```



```graphql
addressSetDefault(addressId: ID!, type: AddressTypeEnum!, userId: ID!): AddressSetDefault
```
