Sets a default address for the authenticated user. 



<Permissions label="Requires one of the following permissions" values="AUTHENTICATED_USER" />



Triggers the following webhook events:
- CUSTOMER_UPDATED (async): A customer's address was updated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [CUSTOMER_UPDATED], syncEvents: [])
```



```graphql

```
