Unassign attributes from a given customer type. Values already assigned to users are kept in the database, but are hidden until the attribute is assigned to the user's customer type again.

Added in Saleor 3.23. 



<Permissions label="Requires one of the following permissions" values="MANAGE_CUSTOMER_TYPES_AND_ATTRIBUTES" />



Triggers the following webhook events:
- CUSTOMER_TYPE_UPDATED (async): A customer type was updated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [CUSTOMER_TYPE_UPDATED], syncEvents: [])
```



```graphql
customerTypeUnassignAttributes(attributeIds: [ID!]!, customerTypeId: ID!): CustomerTypeUnassignAttributes
```

## Arguments

### attributeIds [#attribute-ids]

**`attributeIds`** · [`[ID!]!`](/api-reference/miscellaneous/scalars/id)

The IDs of the attributes to unassign. Maximum of 100 items.

### customerTypeId [#customer-type-id]

**`customerTypeId`** · [`ID!`](/api-reference/miscellaneous/scalars/id)

ID of the customer type from which the attributes should be unassigned.
