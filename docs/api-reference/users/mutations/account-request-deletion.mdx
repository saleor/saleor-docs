Sends an email with the account removal link for the logged-in user. 



<Permissions label="Requires one of the following permissions" values="AUTHENTICATED_USER" />



Triggers the following webhook events:
- NOTIFY_USER (async): A notification for account delete request.
- ACCOUNT_DELETE_REQUESTED (async): An account delete requested.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [NOTIFY_USER, ACCOUNT_DELETE_REQUESTED], syncEvents: [])
```



```graphql
accountRequestDeletion(channel: String, redirectUrl: String!): AccountRequestDeletion
```

## Arguments

### channel [#channel]

**`channel`** · [`String`](/api-reference/miscellaneous/scalars/string)

Slug of a channel which will be used to notify users. Optional when only one channel exists.

### redirectUrl [#redirect-url]

**`redirectUrl`** · [`String!`](/api-reference/miscellaneous/scalars/string)

URL of a view where users should be redirected to delete their account. URL in RFC 1808 format.
