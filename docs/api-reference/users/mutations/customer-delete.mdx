Deletes a customer. 



<Permissions label="Requires one of the following permissions" values="MANAGE_USERS" />



Triggers the following webhook events:
- CUSTOMER_DELETED (async): A customer account was deleted.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [CUSTOMER_DELETED], syncEvents: [])
```



```graphql
customerDelete(externalReference: String, id: ID): CustomerDelete
```
