Creates a new customer type.

Added in Saleor 3.23. 



<Permissions label="Requires one of the following permissions" values="MANAGE_CUSTOMER_TYPES_AND_ATTRIBUTES" />



Triggers the following webhook events:
- CUSTOMER_TYPE_CREATED (async): A new customer type was created.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [CUSTOMER_TYPE_CREATED], syncEvents: [])
```



```graphql

```
