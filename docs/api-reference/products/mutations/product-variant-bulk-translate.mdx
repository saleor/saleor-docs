Creates/updates translations for product variants. 



<Permissions label="Requires one of the following permissions" values="MANAGE_TRANSLATIONS" />



Triggers the following webhook events:
- TRANSLATION_CREATED (async): A translation was created.
- TRANSLATION_UPDATED (async): A translation was updated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [TRANSLATION_CREATED, TRANSLATION_UPDATED], syncEvents: [])
```



```graphql
productVariantBulkTranslate(errorPolicy: ErrorPolicyEnum, translations: [ProductVariantBulkTranslateInput!]!): ProductVariantBulkTranslate
```
