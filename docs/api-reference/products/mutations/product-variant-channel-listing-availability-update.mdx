Toggle whether a product variant can be bought in the given channels, without touching its prices. An unavailable variant is hidden from customers and cannot be added to a checkout or an order.

Added in Saleor 3.23. 



<Permissions label="Requires one of the following permissions" values="MANAGE_PRODUCTS" />





```graphql
productVariantChannelListingAvailabilityUpdate(id: ID, input: [ProductVariantChannelListingAvailabilityInput!]!, sku: String): ProductVariantChannelListingAvailabilityUpdate
```

## Arguments

### id [#id]
