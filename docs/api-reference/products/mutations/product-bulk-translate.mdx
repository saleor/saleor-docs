Creates/updates translations for products. 



<Permissions label="Requires one of the following permissions" values="MANAGE_TRANSLATIONS" />



Triggers the following webhook events:
- TRANSLATION_CREATED (async): Called when a translation was created.
- TRANSLATION_UPDATED (async): Called when a translation was updated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [TRANSLATION_CREATED, TRANSLATION_UPDATED], syncEvents: [])
```



```graphql
productBulkTranslate(errorPolicy: ErrorPolicyEnum, translations: [ProductBulkTranslateInput!]!): ProductBulkTranslate
```
