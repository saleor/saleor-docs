```graphql
enum ProductOrderField {
  NAME
  RANK
  PRICE
  MINIMAL_PRICE
  LAST_MODIFIED @deprecated(reason: "Use `LAST_MODIFIED_AT` instead.")
  DATE @deprecated(reason: "Use `LAST_MODIFIED_AT` instead.")

  PUBLISHED_AT
  LAST_MODIFIED_AT

```


## Values

### NAME [#name]

`NAME`

Sort products by name.

### RANK [#rank]

`RANK`

Sort products by rank. Note: This option is available only with the `search` filter.

### PRICE [#price]

`PRICE`

Sort products by price.

This option requires a channel filter to work as the values can vary between channels.

### MINIMAL_PRICE [#minimal-price]

`MINIMAL_PRICE`

Sort products by a minimal price of a product's variant.

This option requires a channel filter to work as the values can vary between channels.

### LAST_MODIFIED [#last-modified]

`LAST_MODIFIED`

Sort products by update date.

:::warning[Deprecated]
Use `LAST_MODIFIED_AT` instead.
:::


### DATE [#date]

`DATE`

Sort products by update date.

:::warning[Deprecated]
Use `LAST_MODIFIED_AT` instead.
:::


### TYPE [#type]

`TYPE`

Sort products by type.

### PUBLISHED [#published]

`PUBLISHED`

Sort products by publication status.

This option requires a channel filter to work as the values can vary between channels.

### PUBLICATION_DATE [#publication-date]

`PUBLICATION_DATE`

Sort products by publication date.

This option requires a channel filter to work as the values can vary between channels.

:::warning[Deprecated]
Use `PUBLISHED_AT` instead.
:::


### PUBLISHED_AT [#published-at]

`PUBLISHED_AT`

Sort products by publication date.

This option requires a channel filter to work as the values can vary between channels.

### LAST_MODIFIED_AT [#last-modified-at]

`LAST_MODIFIED_AT`

Sort products by update date.

### COLLECTION [#collection]

`COLLECTION`

Sort products by collection. Note: This option is available only for the `Collection.products` query.

This option requires a channel filter to work as the values can vary between channels.

### RATING [#rating]

`RATING`

Sort products by rating.

:::warning[Deprecated]
Product rating is deprecated and will be removed. Use a numeric attribute instead.
:::


### CREATED_AT [#created-at]

`CREATED_AT`

Sort products by creation date.
