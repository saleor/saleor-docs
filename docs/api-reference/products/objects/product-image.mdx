Represents a product image.



```graphql
type ProductImage {
  id: ID!
  alt: String
  sortOrder: Int
  url(size: Int, sizeRounding: ThumbnailSizeRoundingEnum = NEAREST, format: ThumbnailFormatEnum = ORIGINAL): String!
}
```


## Fields

### id [#id]

**`id`** · [`ID!`](/api-reference/miscellaneous/scalars/id)

The ID of the image.
### alt [#alt]

**`alt`** · [`String`](/api-reference/miscellaneous/scalars/string)

The alt text of the image.
### sortOrder [#sort-order]

**`sortOrder`** · [`Int`](/api-reference/miscellaneous/scalars/int)

The new relative sorting position of the item (from -inf to +inf). 1 moves the item one position forward, -1 moves the item one position backward, 0 leaves the item unchanged.
### url [#url]

**`url`** · [`String!`](/api-reference/miscellaneous/scalars/string)

The URL of the image.

#### size [#product-image-url-size]

**`size`** · [`Int`](/api-reference/miscellaneous/scalars/int)

Desired longest side the image in pixels. Defaults to 4096. Images are never cropped. Pass 0 to retrieve the original size (not recommended). Thumbnails are generated only in the available sizes: 32, 64, 128, 256, 512, 1024, 2048, 4096; `sizeRounding` determines which one is used.

#### sizeRounding [#product-image-url-size-rounding]

**`sizeRounding`** · [`ThumbnailSizeRoundingEnum`](/api-reference/miscellaneous/enums/thumbnail-size-rounding-enum)

Determines how the requested size is matched to an available thumbnail size.

<Badge variant="accent">Added in Saleor 3.23</Badge>

Default: `NEAREST`.

#### format [#product-image-url-format]

**`format`** · [`ThumbnailFormatEnum`](/api-reference/miscellaneous/enums/thumbnail-format-enum)

The format of the image. When not provided, format of the original image will be used.

Default: `ORIGINAL`.
