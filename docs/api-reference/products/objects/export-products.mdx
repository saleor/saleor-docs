Export products to csv file. 



<Permissions label="Requires one of the following permissions" values="MANAGE_PRODUCTS" />



Triggers the following webhook events:
- NOTIFY_USER (async): A notification for the exported file.
- PRODUCT_EXPORT_COMPLETED (async): A notification for the exported file.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [NOTIFY_USER, PRODUCT_EXPORT_COMPLETED], syncEvents: [])
```
