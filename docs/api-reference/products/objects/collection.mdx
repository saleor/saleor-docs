Represents a collection of products.



```graphql
type Collection implements Node & ObjectWithMetadata {
  id: ID!
  privateMetadata: [MetadataItem!]!
  privateMetafield(key: String!): String
  privateMetafields(keys: [String!]): Metadata
  metadata: [MetadataItem!]!
  metafield(key: String!): String
  metafields(keys: [String!]): Metadata
  seoTitle: String
  seoDescription: String
  name: String!
  description: JSONString
  fullDescription: JSONString
  slug: String!
  externalReference: String
  channel: String
  descriptionJson: JSONString @deprecated(reason: "Use the `description` field instead.")
  products(filter: ProductFilterInput @deprecated(reason: "Use `where` filter instead."), where: ProductWhereInput, search: String, sortBy: ProductOrder, before: String, after: String, first: Int, last: Int): ProductCountableConnection
  backgroundImage(size: Int, sizeRounding: ThumbnailSizeRoundingEnum = NEAREST, format: ThumbnailFormatEnum = ORIGINAL): Image
  translation(languageCode: LanguageCodeEnum!): CollectionTranslation
  channelListings: [CollectionChannelListing!]
}
```

### backgroundImage [#background-image]

**`backgroundImage`** · [`Image`](/api-reference/miscellaneous/objects/image)

Background image of the collection.

#### size [#collection-background-image-size]

**`size`** · [`Int`](/api-reference/miscellaneous/scalars/int)

Desired longest side the image in pixels. Defaults to 4096. Images are never cropped. Pass 0 to retrieve the original size (not recommended). Thumbnails are generated only in the available sizes: 32, 64, 128, 256, 512, 1024, 2048, 4096; `sizeRounding` determines which one is used.

#### sizeRounding [#collection-background-image-size-rounding]

**`sizeRounding`** · [`ThumbnailSizeRoundingEnum`](/api-reference/miscellaneous/enums/thumbnail-size-rounding-enum)

Determines how the requested size is matched to an available thumbnail size.

<Badge variant="accent">Added in Saleor 3.23</Badge>

Default: `NEAREST`.

#### format [#collection-background-image-format]

**`format`** · [`ThumbnailFormatEnum`](/api-reference/miscellaneous/enums/thumbnail-format-enum)

The format of the image. When not provided, format of the original image will be used.

Default: `ORIGINAL`.
