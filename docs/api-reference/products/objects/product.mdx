Represents an individual item for sale in the storefront.



```graphql
type Product implements Node & ObjectWithMetadata & ObjectWithAttributes {
  id: ID!
  privateMetadata: [MetadataItem!]!
  privateMetafield(key: String!): String
  privateMetafields(keys: [String!]): Metadata
  metadata: [MetadataItem!]!
  metafield(key: String!): String
  metafields(keys: [String!]): Metadata
  assignedAttribute(slug: String!): AssignedAttribute
  assignedAttributes(limit: PositiveInt = 100): [AssignedAttribute!]!
  seoTitle: String
  seoDescription: String
  name: String!
  description: JSONString
  productType: ProductType!
  slug: String!
  category: Category
  created: DateTime!
  updatedAt: DateTime!
  chargeTaxes: Boolean! @deprecated(reason: "Use `Channel.taxConfiguration` field to determine whether tax collection is enabled.")
  weight: Weight
  defaultVariant: ProductVariant
  rating: Float @deprecated(reason: "Product rating is deprecated and will be removed. Use a numeric attribute instead.")
  channel: String
  descriptionJson: JSONString @deprecated(reason: "Use the `description` field instead.")
  thumbnail(size: Int, sizeRounding: ThumbnailSizeRoundingEnum = NEAREST, format: ThumbnailFormatEnum = ORIGINAL): Image
  pricing(address: AddressInput): ProductPricingInfo
  isAvailable(address: AddressInput @deprecated): Boolean
  taxType: TaxType @deprecated(reason: "Use `taxClass` field instead.")
  attribute(slug: String!): SelectedAttribute @deprecated(reason: "Use the `assignedAttribute` field instead.")
  attributes: [SelectedAttribute!]! @deprecated(reason: "Use the `assignedAttributes` field instead.")
  channelListings: [ProductChannelListing!]
  mediaById(id: ID!): ProductMedia
  imageById(id: ID!): ProductImage @deprecated(reason: "Use the `mediaById` field instead.")
  variant(id: ID, sku: String): ProductVariant @deprecated(reason: "Use top-level `variant` query.")
  variants: [ProductVariant!] @deprecated(reason: "Use `productVariants` field instead.")
  productVariants(filter: ProductVariantFilterInput @deprecated(reason: "Use `where` filter instead."), where: ProductVariantWhereInput, sortBy: ProductVariantSortingInput, before: String, after: String, first: Int, last: Int): ProductVariantCountableConnection
  media(sortBy: MediaSortingInput): [ProductMedia!]
  images: [ProductImage!] @deprecated(reason: "Use the `media` field instead.")
  collections: [Collection!]
  translation(languageCode: LanguageCodeEnum!): ProductTranslation
  availableForPurchase: Date @deprecated(reason: "Use the `availableForPurchaseAt` field to fetch the available for purchase date.")
  availableForPurchaseAt: DateTime
  isAvailableForPurchase: Boolean
  taxClass: TaxClass
  externalReference: String
}
```

### thumbnail [#thumbnail]

**`thumbnail`** · [`Image`](/api-reference/miscellaneous/objects/image)

Thumbnail of the product.

#### size [#product-thumbnail-size]

**`size`** · [`Int`](/api-reference/miscellaneous/scalars/int)

Desired longest side the image in pixels. Defaults to 4096. Images are never cropped. Pass 0 to retrieve the original size (not recommended). Thumbnails are generated only in the available sizes: 32, 64, 128, 256, 512, 1024, 2048, 4096; `sizeRounding` determines which one is used.

#### sizeRounding [#product-thumbnail-size-rounding]

**`sizeRounding`** · [`ThumbnailSizeRoundingEnum`](/api-reference/miscellaneous/enums/thumbnail-size-rounding-enum)

Determines how the requested size is matched to an available thumbnail size.

<Badge variant="accent">Added in Saleor 3.23</Badge>

Default: `NEAREST`.

#### format [#product-thumbnail-format]

**`format`** · [`ThumbnailFormatEnum`](/api-reference/miscellaneous/enums/thumbnail-format-enum)

The format of the image. When not provided, format of the original image will be used.

Default: `ORIGINAL`.

#### address [#product-pricing-address]

**`address`** · [`AddressInput`](/api-reference/miscellaneous/inputs/address-input)

Destination address used to find warehouses where stock availability for this product is checked. If address is empty, uses `Shop.companyAddress` or fallbacks to server's `settings.DEFAULT_COUNTRY` configuration.
### isAvailable [#is-available]

**`isAvailable`** · [`Boolean`](/api-reference/miscellaneous/scalars/boolean)

Whether the product is in stock, set as available for purchase in the given channel, and published.

#### address [#product-is-available-address]

**`address`** · [`AddressInput`](/api-reference/miscellaneous/inputs/address-input)

Destination address used to find warehouses where stock availability for this product is checked. If address is empty, uses `Shop.companyAddress` or fallbacks to server's `settings.DEFAULT_COUNTRY` configuration. When `Shop.useLegacyShippingZoneStockAvailability` is disabled, this argument is ignored — stock availability is determined by the direct warehouse-channel link instead of shipping zones.

:::warning[Deprecated]
No longer supported
:::
