```graphql
type ProductError {
  field: String
  message: String
  code: ProductErrorCode!
  attributes: [ID!]
  values: [ID!]
}
```


## Fields

### field [#field]

**`field`** · [`String`](/api-reference/miscellaneous/scalars/string)

Name of a field that caused the error. A value of `null` indicates that the error isn't associated with a particular field.
### message [#message]

**`message`** · [`String`](/api-reference/miscellaneous/scalars/string)

The error message.
### code [#code]

**`code`** · [`ProductErrorCode!`](/api-reference/products/enums/product-error-code)

The error code.
### attributes [#attributes]

**`attributes`** · [`[ID!]`](/api-reference/miscellaneous/scalars/id)

List of attributes IDs which causes the error.
### values [#values]

**`values`** · [`[ID!]`](/api-reference/miscellaneous/scalars/id)

List of attribute values IDs which causes the error.
