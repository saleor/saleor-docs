Represents availability of a product in the storefront.



```graphql
type ProductPricingInfo {
  onSale: Boolean
  discount: TaxedMoney
  discountPrior: TaxedMoney
  discountLocalCurrency: TaxedMoney @deprecated(reason: "Always returns `null`.")
  displayGrossPrices: Boolean!
  priceRange: TaxedMoneyRange
  priceRangeUndiscounted: TaxedMoneyRange
  priceRangePrior: TaxedMoneyRange
  priceRangeLocalCurrency: TaxedMoneyRange @deprecated(reason: "Always returns `null`.")
}
```


## Fields

### onSale [#on-sale]

**`onSale`** · [`Boolean`](/api-reference/miscellaneous/scalars/boolean)

Whether it is in sale or not.
### discount [#discount]

**`discount`** · [`TaxedMoney`](/api-reference/miscellaneous/objects/taxed-money)

The discount amount if in sale (null otherwise).
### discountPrior [#discount-prior]

**`discountPrior`** · [`TaxedMoney`](/api-reference/miscellaneous/objects/taxed-money)

The discount amount compared to prior price. Null if product is not on sale or prior price was not provided in VariantChannelListing

<Badge variant="accent">Added in Saleor 3.21</Badge>
### discountLocalCurrency [#discount-local-currency]

**`discountLocalCurrency`** · [`TaxedMoney`](/api-reference/miscellaneous/objects/taxed-money)

The discount amount in the local currency.

:::warning[Deprecated]
Always returns `null`.
:::

### displayGrossPrices [#display-gross-prices]

**`displayGrossPrices`** · [`Boolean!`](/api-reference/miscellaneous/scalars/boolean)

Determines whether displayed prices should include taxes.
### priceRange [#price-range]

**`priceRange`** · [`TaxedMoneyRange`](/api-reference/miscellaneous/objects/taxed-money-range)

The discounted price range of the product variants.
### priceRangeUndiscounted [#price-range-undiscounted]

**`priceRangeUndiscounted`** · [`TaxedMoneyRange`](/api-reference/miscellaneous/objects/taxed-money-range)

The undiscounted price range of the product variants.
### priceRangePrior [#price-range-prior]

**`priceRangePrior`** · [`TaxedMoneyRange`](/api-reference/miscellaneous/objects/taxed-money-range)

The prior price range of the product variants.

<Badge variant="accent">Added in Saleor 3.21</Badge>
### priceRangeLocalCurrency [#price-range-local-currency]

**`priceRangeLocalCurrency`** · [`TaxedMoneyRange`](/api-reference/miscellaneous/objects/taxed-money-range)

The discounted price range of the product variants in the local currency.

:::warning[Deprecated]
Always returns `null`.
:::
