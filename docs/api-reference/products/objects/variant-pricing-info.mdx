Represents availability of a variant in the storefront.



```graphql
type VariantPricingInfo {
  onSale: Boolean
  discount: TaxedMoney
  discountPrior: TaxedMoney
  discountLocalCurrency: TaxedMoney @deprecated(reason: "Always returns `null`.")
  price: TaxedMoney
  priceUndiscounted: TaxedMoney
  pricePrior: TaxedMoney
  priceLocalCurrency: TaxedMoney @deprecated(reason: "Always returns `null`.")
}
```


## Fields

### onSale [#on-sale]

**`onSale`** · [`Boolean`](/api-reference/miscellaneous/scalars/boolean)

Whether it is in sale or not.
### discount [#discount]

**`discount`** · [`TaxedMoney`](/api-reference/miscellaneous/objects/taxed-money)

The discount amount if in sale (null otherwise).
### discountPrior [#discount-prior]

**`discountPrior`** · [`TaxedMoney`](/api-reference/miscellaneous/objects/taxed-money)

The discount amount compared to prior price. Null if product is not on sale or prior price was not provided in VariantChannelListing

<Badge variant="accent">Added in Saleor 3.21</Badge>
### discountLocalCurrency [#discount-local-currency]

**`discountLocalCurrency`** · [`TaxedMoney`](/api-reference/miscellaneous/objects/taxed-money)

The discount amount in the local currency.

:::warning[Deprecated]
Always returns `null`.
:::

### price [#price]

**`price`** · [`TaxedMoney`](/api-reference/miscellaneous/objects/taxed-money)

The price, with any discount subtracted.
### priceUndiscounted [#price-undiscounted]

**`priceUndiscounted`** · [`TaxedMoney`](/api-reference/miscellaneous/objects/taxed-money)

The price without any discount.
### pricePrior [#price-prior]

**`pricePrior`** · [`TaxedMoney`](/api-reference/miscellaneous/objects/taxed-money)

The price prior to discount.

<Badge variant="accent">Added in Saleor 3.21</Badge>
### priceLocalCurrency [#price-local-currency]

**`priceLocalCurrency`** · [`TaxedMoney`](/api-reference/miscellaneous/objects/taxed-money)

The discounted price in the local currency.

:::warning[Deprecated]
Always returns `null`.
:::
