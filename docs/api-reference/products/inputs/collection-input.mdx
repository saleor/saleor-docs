```graphql
input CollectionInput {
  isPublished: Boolean
  name: String
  slug: String
  externalReference: String
  description: JSONString
  fullDescription: JSONString
  backgroundImage: Upload
  backgroundImageAlt: String
  seo: SeoInput
  publicationDate: Date @deprecated
  metadata: [MetadataInput!]
  privateMetadata: [MetadataInput!]
}
```


## Fields

### isPublished [#is-published]

**`isPublished`** · [`Boolean`](/api-reference/miscellaneous/scalars/boolean)

Informs whether a collection is published.
### name [#name]

**`name`** · [`String`](/api-reference/miscellaneous/scalars/string)

Name of the collection.
### slug [#slug]

**`slug`** · [`String`](/api-reference/miscellaneous/scalars/string)

Slug of the collection.
### externalReference [#external-reference]

**`externalReference`** · [`String`](/api-reference/miscellaneous/scalars/string)

External ID of this collection.

<Badge variant="accent">Added in Saleor 3.23</Badge>
### description [#description]

**`description`** · [`JSONString`](/api-reference/miscellaneous/scalars/jsonstring)

Description of the collection.

Rich text format. For reference see https://editorjs.io/
### fullDescription [#full-description]

**`fullDescription`** · [`JSONString`](/api-reference/miscellaneous/scalars/jsonstring)

Full description of the collection. Pass null to clear it. Omit to preserve the current value on update.

Rich text format. For reference see https://editorjs.io/

<Badge variant="accent">Added in Saleor 3.23</Badge>
### backgroundImage [#background-image]

**`backgroundImage`** · [`Upload`](/api-reference/miscellaneous/scalars/upload)

Background image file.
### backgroundImageAlt [#background-image-alt]

**`backgroundImageAlt`** · [`String`](/api-reference/miscellaneous/scalars/string)

Alt text for an image.
### seo [#seo]

**`seo`** · [`SeoInput`](/api-reference/miscellaneous/inputs/seo-input)

Search engine optimization fields.
### publicationDate [#publication-date]

**`publicationDate`** · [`Date`](/api-reference/miscellaneous/scalars/date)

Publication date. ISO 8601 standard.

:::warning[Deprecated]
No longer supported
:::

### metadata [#metadata]

**`metadata`** · [`[MetadataInput!]`](/api-reference/miscellaneous/inputs/metadata-input)

Fields required to update the collection metadata. Can be read by any API client authorized to read the object it's attached to.

Warning: never store sensitive information, including financial data such as credit card details.
### privateMetadata [#private-metadata]

**`privateMetadata`** · [`[MetadataInput!]`](/api-reference/miscellaneous/inputs/metadata-input)

Fields required to update the collection private metadata. Requires permissions to modify and to read the metadata of the object it's attached to.

Warning: never store sensitive information, including financial data such as credit card details.
