## Fields

### channelId [#channel-id]

**`channelId`** · [`ID!`](/api-reference/miscellaneous/scalars/id)

ID of a channel.
### isPublished [#is-published]

**`isPublished`** · [`Boolean`](/api-reference/miscellaneous/scalars/boolean)

Determines if object is visible to customers.
### publishedAt [#published-at]

**`publishedAt`** · [`DateTime`](/api-reference/miscellaneous/scalars/date-time)

Publication date time. ISO 8601 standard.
### visibleInListings [#visible-in-listings]

**`visibleInListings`** · [`Boolean`](/api-reference/miscellaneous/scalars/boolean)

Determines if product is visible in product listings (doesn't apply to product collections).
### isAvailableForPurchase [#is-available-for-purchase]

**`isAvailableForPurchase`** · [`Boolean`](/api-reference/miscellaneous/scalars/boolean)

Determines if product should be available for purchase in this channel. This does not guarantee the availability of stock. When set to `False`, this product is still visible to customers, but it cannot be purchased.
### availableForPurchaseAt [#available-for-purchase-at]

**`availableForPurchaseAt`** · [`DateTime`](/api-reference/miscellaneous/scalars/date-time)

A start date time from which a product will be available for purchase. When not set and `isAvailable` is set to True, the current day is assumed.
