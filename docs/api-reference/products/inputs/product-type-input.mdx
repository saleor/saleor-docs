### hasVariants [#has-variants]

**`hasVariants`** · [`Boolean`](/api-reference/miscellaneous/scalars/boolean)

Determines if product of this type has multiple variants. This option mainly simplifies product management in the dashboard. There is always at least one variant created under the hood.

:::warning[Deprecated]
The field has no effect on the API behavior. This is a leftover from the past Simple/Configurable product distinction. Products can have multiple variants regardless of this setting.
:::

### productAttributes [#product-attributes]

**`productAttributes`** · [`[ID!]`](/api-reference/miscellaneous/scalars/id)

List of attributes shared among all product variants.
### variantAttributes [#variant-attributes]

**`variantAttributes`** · [`[ID!]`](/api-reference/miscellaneous/scalars/id)

List of attributes used to distinguish between different variants of a product.
### isShippingRequired [#is-shipping-required]

**`isShippingRequired`** · [`Boolean`](/api-reference/miscellaneous/scalars/boolean)

Determines if shipping is required for products of this variant.
### isDigital [#is-digital]

**`isDigital`** · [`Boolean`](/api-reference/miscellaneous/scalars/boolean)

Determines if products are digital - doesn't have any effect, it's present for backward-compatibility.
### weight [#weight]

**`weight`** · [`WeightScalar`](/api-reference/miscellaneous/scalars/weight-scalar)

Weight of the ProductType items.
### taxCode [#tax-code]

**`taxCode`** · [`String`](/api-reference/miscellaneous/scalars/string)

Tax rate for enabled tax gateway.

:::warning[Deprecated]
Use tax classes to control the tax calculation for a product type. If taxCode is provided, Saleor will try to find a tax class with given code (codes are stored in metadata) and assign it. If no tax class is found, it would be created and assigned.
:::

### taxClass [#tax-class]

**`taxClass`** · [`ID`](/api-reference/miscellaneous/scalars/id)

ID of a tax class to assign to this product type. All products of this product type would use this tax class, unless it's overridden in the `Product` type.
