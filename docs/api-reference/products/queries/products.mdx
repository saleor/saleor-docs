
Where filtering options for products.

Sort products.

### search [#search]

**`search`** · [`String`](/api-reference/miscellaneous/scalars/string)

Search products.

### channel [#channel]

**`channel`** · [`String`](/api-reference/miscellaneous/scalars/string)

Slug of a channel for which the data should be returned.

### before [#before]

**`before`** · [`String`](/api-reference/miscellaneous/scalars/string)

Return the elements in the list that come before the specified cursor.

### after [#after]

**`after`** · [`String`](/api-reference/miscellaneous/scalars/string)

Return the elements in the list that come after the specified cursor.

### first [#first]

**`first`** · [`Int`](/api-reference/miscellaneous/scalars/int)

Retrieve the first n elements from the list. Note that the system only allows fetching a maximum of 100 objects in a single query.

### last [#last]

**`last`** · [`Int`](/api-reference/miscellaneous/scalars/int)

Retrieve the last n elements from the list. Note that the system only allows fetching a maximum of 100 objects in a single query.
