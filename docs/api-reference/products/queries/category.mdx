Look up a category by ID, slug or external reference. If slugLanguageCode is provided, category will be fetched by slug translation.



```graphql
category(id: ID, slug: String, slugLanguageCode: LanguageCodeEnum, externalReference: String): Category
```

## Arguments

### id [#id]

ID of the category.

### slug [#slug]

**`slug`** · [`String`](/api-reference/miscellaneous/scalars/string)

Slug of the category

### slugLanguageCode [#slug-language-code]

**`slugLanguageCode`** · [`LanguageCodeEnum`](/api-reference/miscellaneous/enums/language-code-enum)

Language code of the category slug, omit to use primary slug.
