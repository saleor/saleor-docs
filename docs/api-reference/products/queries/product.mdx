Look up a product by ID. 

<Permissions label="Requires one of the following permissions to include the unpublished items" values="MANAGE_ORDERS,MANAGE_DISCOUNTS,MANAGE_PRODUCTS" />





```graphql
product(id: ID, slug: String, slugLanguageCode: LanguageCodeEnum, externalReference: String, channel: String): Product
```

## Arguments

### id [#id]

**`id`** · [`ID`](/api-reference/miscellaneous/scalars/id)

ID of the product.

### slug [#slug]

**`slug`** · [`String`](/api-reference/miscellaneous/scalars/string)

Slug of the product.

### slugLanguageCode [#slug-language-code]

**`slugLanguageCode`** · [`LanguageCodeEnum`](/api-reference/miscellaneous/enums/language-code-enum)

Language code of the product slug, omit to use primary slug.

<Badge variant="accent">Added in Saleor 3.21</Badge>

### externalReference [#external-reference]

**`externalReference`** · [`String`](/api-reference/miscellaneous/scalars/string)

External ID of the product.

### channel [#channel]

**`channel`** · [`String`](/api-reference/miscellaneous/scalars/string)

Slug of a channel for which the data should be returned.
