List of checkouts. The query will not initiate any external requests, including fetching external shipping methods, filtering available shipping methods, or performing external tax calculations.



<Permissions label="Requires one of the following permissions" values="MANAGE_CHECKOUTS,HANDLE_PAYMENTS" />





```graphql
checkouts(sortBy: CheckoutSortingInput, filter: CheckoutFilterInput, channel: String, before: String, after: String, first: Int, last: Int): CheckoutCountableConnection
```
