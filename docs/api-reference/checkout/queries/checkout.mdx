<Permissions label="Requires one of the following permissions to query a checkout, if a checkout is in inactive channel" values="MANAGE_CHECKOUTS,IMPERSONATE_USER,HANDLE_PAYMENTS" />





```graphql
checkout(id: ID, token: UUID): Checkout
```
