Updates customer note in the existing checkout object.

<Badge variant="accent">Added in Saleor 3.21</Badge>

Triggers the following webhook events:
- CHECKOUT_UPDATED (async): A checkout was updated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [CHECKOUT_UPDATED], syncEvents: [])
```



```graphql
checkoutCustomerNoteUpdate(customerNote: String!, id: ID!): CheckoutCustomerNoteUpdate
```
