Sets the customer as the owner of the checkout. 



<Permissions label="Requires one of the following permissions" values="AUTHENTICATED_APP,AUTHENTICATED_USER" />



Triggers the following webhook events:
- CHECKOUT_UPDATED (async): A checkout was updated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [CHECKOUT_UPDATED], syncEvents: [])
```



```graphql
checkoutCustomerAttach(checkoutId: ID, customerId: ID, id: ID, token: UUID): CheckoutCustomerAttach
```

## Arguments

### checkoutId [#checkout-id]

**`checkoutId`** · [`ID`](/api-reference/miscellaneous/scalars/id)

### customerId [#customer-id]

**`customerId`** · [`ID`](/api-reference/miscellaneous/scalars/id)

ID of customer to attach to checkout. Requires IMPERSONATE_USER permission when customerId is different than the logged-in user.

### id [#id]

**`id`** · [`ID`](/api-reference/miscellaneous/scalars/id)
