Adds a gift card or a voucher to a checkout.

Triggers the following webhook events:
- CHECKOUT_UPDATED (async): A checkout was updated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [CHECKOUT_UPDATED], syncEvents: [])
```



```graphql
checkoutAddPromoCode(checkoutId: ID, id: ID, promoCode: String!, token: UUID): CheckoutAddPromoCode
```
