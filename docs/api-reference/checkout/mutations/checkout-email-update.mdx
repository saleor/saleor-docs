Updates email address in the existing checkout object.

Triggers the following webhook events:
- CHECKOUT_UPDATED (async): A checkout was updated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [CHECKOUT_UPDATED], syncEvents: [])
```



```graphql
checkoutEmailUpdate(checkoutId: ID, email: String!, id: ID, token: UUID): CheckoutEmailUpdate
```
