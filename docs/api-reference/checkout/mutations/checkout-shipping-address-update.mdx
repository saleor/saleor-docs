Updates shipping address in the existing checkout.

Triggers the following webhook events:
- CHECKOUT_UPDATED (async): A checkout was updated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [CHECKOUT_UPDATED], syncEvents: [])
```



```graphql
checkoutShippingAddressUpdate(checkoutId: ID, id: ID, saveAddress: Boolean = true, shippingAddress: AddressInput!, token: UUID, validationRules: CheckoutAddressValidationRules): CheckoutShippingAddressUpdate
```

### saveAddress [#save-address]

**`saveAddress`** · [`Boolean`](/api-reference/miscellaneous/scalars/boolean)

Indicates whether the shipping address should be saved to the user’s address book upon checkout completion. If not provided, the default behavior is to save the address.

<Badge variant="accent">Added in Saleor 3.21</Badge>

Default: `true`.

### shippingAddress [#shipping-address]

**`shippingAddress`** · [`AddressInput!`](/api-reference/miscellaneous/inputs/address-input)
