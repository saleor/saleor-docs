Create a new checkout.

`skipValidation` field requires HANDLE_CHECKOUTS and AUTHENTICATED_APP permissions.

Triggers the following webhook events:
- CHECKOUT_CREATED (async): A checkout was created.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [CHECKOUT_CREATED], syncEvents: [])
```



```graphql
type CheckoutCreate {
  created: Boolean @deprecated(reason: "Always returns `true`.")
  checkoutErrors: [CheckoutError!]! @deprecated(reason: "Use `errors` field instead.")
  errors: [CheckoutError!]!
  checkout: Checkout
}
```
