Details explaining why a promo code cannot be applied.

<Badge variant="accent">Added in Saleor 3.23</Badge>



```graphql
type PromoCodeRejectionDetails {
  reason: PromoCodeRejectionReason!
  minSpent: Money
  minCheckoutItemsQuantity: Int
}
```


## Fields

### reason [#reason]

**`reason`** · [`PromoCodeRejectionReason!`](/api-reference/discounts/enums/promo-code-rejection-reason)

The specific reason why the promo code cannot be applied.
### minSpent [#min-spent]

**`minSpent`** · [`Money`](/api-reference/miscellaneous/objects/money)

The minimum order value required by the voucher. Set only when `reason` is `MIN_SPENT_NOT_REACHED`.
### minCheckoutItemsQuantity [#min-checkout-items-quantity]

**`minCheckoutItemsQuantity`** · [`Int`](/api-reference/miscellaneous/scalars/int)

The minimum number of items required by the voucher. Set only when `reason` is `MIN_QUANTITY_NOT_REACHED`.
