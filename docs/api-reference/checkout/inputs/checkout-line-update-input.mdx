```graphql
input CheckoutLineUpdateInput {
  variantId: ID @deprecated(reason: "Use `lineId` instead.")
  quantity: Int
  price: PositiveDecimal

  lineId: ID

}
```


## Fields

### variantId [#variant-id]

**`variantId`** · [`ID`](/api-reference/miscellaneous/scalars/id)

ID of the product variant.

:::warning[Deprecated]
Use `lineId` instead.
:::

### quantity [#quantity]

**`quantity`** · [`Int`](/api-reference/miscellaneous/scalars/int)

The number of items purchased. Optional for apps, required for any other users.
### price [#price]

**`price`** · [`PositiveDecimal`](/api-reference/miscellaneous/scalars/positive-decimal)

Custom price of the item. Can be set only by apps with `HANDLE_CHECKOUTS` permission. When the line with the same variant will be provided multiple times, the last price will be used.
### priceOverrideReason [#price-override-reason]

**`priceOverrideReason`** · [`String`](/api-reference/miscellaneous/scalars/string)

Reason explaining why a custom `price` was set on the line, for debugging and auditing. Can be set only by apps with `HANDLE_CHECKOUTS` permission and only when the line has a `price` override. Setting a new `price` without a reason clears the previous reason. Blank values are stored as no reason. Limited to 255 characters; longer values are truncated.

<Badge variant="accent">Added in Saleor 3.23</Badge>
### lineId [#line-id]

**`lineId`** · [`ID`](/api-reference/miscellaneous/scalars/id)

ID of the line.
### metadata [#metadata]

**`metadata`** · [`[MetadataInput!]`](/api-reference/miscellaneous/inputs/metadata-input)

Checkout line public metadata. Will add and update keys. To delete keys use deleteMetadata mutation. 

Added in Saleor 3.21. Can be read by any API client authorized to read the object it's attached to.

Warning: never store sensitive information, including financial data such as credit card details.
