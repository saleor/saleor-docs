Updates tax class rates for a specific country. 



<Permissions label="Requires one of the following permissions" values="MANAGE_TAXES" />





```graphql
taxCountryConfigurationUpdate(countryCode: CountryCode!, updateTaxClassRates: [TaxClassRateInput!]!): TaxCountryConfigurationUpdate
```

## Returns

[`TaxCountryConfigurationUpdate`](/api-reference/taxes/objects/tax-country-configuration-update)

```graphql
type TaxCountryConfigurationUpdate {
  taxCountryConfiguration: TaxCountryConfiguration
  errors: [TaxCountryConfigurationUpdateError!]!
}
```


</details>

## Arguments

### countryCode [#country-code]

**`countryCode`** · [`CountryCode!`](/api-reference/miscellaneous/enums/country-code)

Country in which to update the tax class rates.

### updateTaxClassRates [#update-tax-class-rates]

**`updateTaxClassRates`** · [`[TaxClassRateInput!]!`](/api-reference/taxes/inputs/tax-class-rate-input)

List of tax rates per tax class to update. When `&#123;taxClass: id, rate: null`&#125; is passed, it deletes the rate object for given taxClass ID. When `&#123;rate: Int&#125;` is passed without a tax class, it updates the default tax class for this country.
