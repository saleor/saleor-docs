Deletes a tax class. After deleting the tax class any products, product types or shipping methods using it are updated to use the default tax class. 



<Permissions label="Requires one of the following permissions" values="MANAGE_TAXES" />





```graphql
taxClassDelete(id: ID!): TaxClassDelete
```

## Arguments

### id [#id]

**`id`** · [`ID!`](/api-reference/miscellaneous/scalars/id)

ID of a tax class to delete.
