Tax rate for a country. When tax class is null, it represents the default tax rate for that country; otherwise it's a country tax rate specific to the given tax class.



```graphql
type TaxClassCountryRate {
  country: CountryDisplay!
  rate: Float!
  taxClass: TaxClass
}
```


## Fields

### country [#country]

**`country`** · [`CountryDisplay!`](/api-reference/miscellaneous/objects/country-display)

### rate [#rate]

**`rate`** · [`Float!`](/api-reference/miscellaneous/scalars/float)

Tax rate value.
### taxClass [#tax-class]

**`taxClass`** · [`TaxClass`](/api-reference/taxes/objects/tax-class)

Related tax class.
