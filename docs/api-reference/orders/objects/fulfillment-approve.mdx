Approve existing fulfillment. 



<Permissions label="Requires one of the following permissions" values="MANAGE_ORDERS" />



Triggers the following webhook events:
- FULFILLMENT_APPROVED (async): Fulfillment is approved.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [FULFILLMENT_APPROVED], syncEvents: [])
```
