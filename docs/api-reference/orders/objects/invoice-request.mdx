Request an invoice for the order using plugin. 



<Permissions label="Requires one of the following permissions" values="MANAGE_ORDERS" />



Triggers the following webhook events:
- INVOICE_REQUESTED (async): An invoice was requested.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [INVOICE_REQUESTED], syncEvents: [])
```



```graphql
type InvoiceRequest {
  order: Order
  invoiceErrors: [InvoiceError!]! @deprecated(reason: "Use `errors` field instead.")
  errors: [InvoiceError!]!
  invoice: Invoice
}
```
