Send an invoice notification to the customer. 



<Permissions label="Requires one of the following permissions" values="MANAGE_ORDERS" />



Triggers the following webhook events:
- INVOICE_SENT (async): A notification for invoice send
- NOTIFY_USER (async): A notification for invoice send



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [INVOICE_SENT, NOTIFY_USER], syncEvents: [])
```
