```graphql
type OrderError {
  field: String
  message: String
  code: OrderErrorCode!
  warehouse: ID
  orderLines: [ID!]
  variants: [ID!]
  addressType: AddressTypeEnum
  promoCodeDetails: PromoCodeRejectionDetails
}
```


## Fields

### field [#field]

**`field`** · [`String`](/api-reference/miscellaneous/scalars/string)

Name of a field that caused the error. A value of `null` indicates that the error isn't associated with a particular field.
### message [#message]

**`message`** · [`String`](/api-reference/miscellaneous/scalars/string)

The error message.
### code [#code]

**`code`** · [`OrderErrorCode!`](/api-reference/orders/enums/order-error-code)

The error code.
### warehouse [#warehouse]

**`warehouse`** · [`ID`](/api-reference/miscellaneous/scalars/id)

Warehouse ID which causes the error.
### orderLines [#order-lines]

**`orderLines`** · [`[ID!]`](/api-reference/miscellaneous/scalars/id)

List of order line IDs that cause the error.
### variants [#variants]

**`variants`** · [`[ID!]`](/api-reference/miscellaneous/scalars/id)

List of product variants that are associated with the error
### addressType [#address-type]

**`addressType`** · [`AddressTypeEnum`](/api-reference/miscellaneous/enums/address-type-enum)

A type of address that causes the error.
### promoCodeDetails [#promo-code-details]

**`promoCodeDetails`** · [`PromoCodeRejectionDetails`](/api-reference/checkout/objects/promo-code-rejection-details)

Details of the promo code that caused the error. Null when the error is not a promo code rejection.
