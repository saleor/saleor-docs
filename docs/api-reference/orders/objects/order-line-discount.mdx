Represent the discount applied to order line.



```graphql
type OrderLineDiscount {
  id: ID!
  type: OrderDiscountType!
  name: String
  translatedName: String
  valueType: DiscountValueTypeEnum!
  value: PositiveDecimal!
  reason: String
  total: Money!
  unit: Money!
}
```

### id [#id]

### name [#name]

**`name`** · [`String`](/api-reference/miscellaneous/scalars/string)

The name of applied discount.
### translatedName [#translated-name]

**`translatedName`** · [`String`](/api-reference/miscellaneous/scalars/string)

Translated name of the applied discount.
### valueType [#value-type]

**`valueType`** · [`DiscountValueTypeEnum!`](/api-reference/discounts/enums/discount-value-type-enum)

### value [#value]
