Represents order line of particular order.



```graphql
type OrderLine implements Node & ObjectWithMetadata {
  id: ID!
  privateMetadata: [MetadataItem!]!
  privateMetafield(key: String!): String
  privateMetafields(keys: [String!]): Metadata
  metadata: [MetadataItem!]!
  metafield(key: String!): String
  metafields(keys: [String!]): Metadata
  productName: String!
  variantName: String!
  productSku: String
  productVariantId: String
  isShippingRequired: Boolean!
  quantity: Int!
  quantityFulfilled: Int!
  taxRate: Float!
  thumbnail(size: Int, sizeRounding: ThumbnailSizeRoundingEnum = NEAREST, format: ThumbnailFormatEnum = ORIGINAL): Image
  unitPrice: TaxedMoney!
  undiscountedUnitPrice: TaxedMoney!
  unitDiscount: Money!
  unitDiscountReason: String
  unitDiscountValue: PositiveDecimal!
  unitDiscountType: DiscountValueTypeEnum
  totalPrice: TaxedMoney!
  undiscountedTotalPrice: TaxedMoney!
  isPriceOverridden: Boolean
  priceOverrideReason: String
  variant: ProductVariant
  translatedProductName: String!
  translatedVariantName: String!
  allocations: [Allocation!]
  saleId: ID
  quantityToFulfill: Int!
  taxClass: TaxClass
  taxClassName: String
  taxClassMetadata: [MetadataItem!]!
  taxClassPrivateMetadata: [MetadataItem!]!
  voucherCode: String
  isGift: Boolean
  discounts: [OrderLineDiscount!]
}
```

#### size [#order-line-thumbnail-size]

**`size`** · [`Int`](/api-reference/miscellaneous/scalars/int)

Desired longest side the image in pixels. Defaults to 4096. Images are never cropped. Pass 0 to retrieve the original size (not recommended). Thumbnails are generated only in the available sizes: 32, 64, 128, 256, 512, 1024, 2048, 4096; `sizeRounding` determines which one is used.

#### sizeRounding [#order-line-thumbnail-size-rounding]

**`sizeRounding`** · [`ThumbnailSizeRoundingEnum`](/api-reference/miscellaneous/enums/thumbnail-size-rounding-enum)

Determines how the requested size is matched to an available thumbnail size.

<Badge variant="accent">Added in Saleor 3.23</Badge>

Default: `NEAREST`.

#### format [#order-line-thumbnail-format]

**`format`** · [`ThumbnailFormatEnum`](/api-reference/miscellaneous/enums/thumbnail-format-enum)

The format of the image. When not provided, format of the original image will be used.

Default: `ORIGINAL`.

### unitDiscount [#unit-discount]

**`unitDiscount`** · [`Money!`](/api-reference/miscellaneous/objects/money)

Sum of the line-level discounts applied to the order line. Order-level discounts which affect the line are not visible in this field. For order-level discount portion (if any), please query `order.discounts` field.
### unitDiscountReason [#unit-discount-reason]

**`unitDiscountReason`** · [`String`](/api-reference/miscellaneous/scalars/string)

Reason for line-level discounts applied on the order line. Order-level discounts which affect the line are not visible in this field. For order-level discount reason (if any), please query `order.discounts` field.
### unitDiscountValue [#unit-discount-value]

**`unitDiscountValue`** · [`PositiveDecimal!`](/api-reference/miscellaneous/scalars/positive-decimal)

Value of the discount. Can store fixed value or percent value. This field shouldn't be used when multiple discounts affect the line. There is a limitation, that after running `checkoutComplete` mutation the field always stores fixed value.
### unitDiscountType [#unit-discount-type]

**`unitDiscountType`** · [`DiscountValueTypeEnum`](/api-reference/discounts/enums/discount-value-type-enum)

Type of the discount: `fixed` or `percent`. This field shouldn't be used when multiple discounts affect the line. There is a limitation, that after running `checkoutComplete` mutation the field is always set to `fixed`.
