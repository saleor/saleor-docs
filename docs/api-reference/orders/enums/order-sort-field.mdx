```graphql
enum OrderSortField {
  NUMBER
  RANK
  CREATION_DATE @deprecated(reason: "Use `CREATED_AT` instead.")
  CREATED_AT
  LAST_MODIFIED_AT
  CUSTOMER
  PAYMENT @deprecated(reason: "The legacy Payments API is deprecated and will be removed. Use the Transactions API instead.")
  FULFILLMENT_STATUS @deprecated(reason: "Use `STATUS` instead.")
  STATUS
}
```


## Values

### NUMBER [#number]

`NUMBER`

Sort orders by number.

### RANK [#rank]

`RANK`

Sort orders by rank. Note: This option is available only with the `search` filter.

### CREATION_DATE [#creation-date]

`CREATION_DATE`

Sort orders by creation date

:::warning[Deprecated]
Use `CREATED_AT` instead.
:::


### CREATED_AT [#created-at]

`CREATED_AT`

Sort orders by creation date.

### LAST_MODIFIED_AT [#last-modified-at]

`LAST_MODIFIED_AT`

Sort orders by last modified date.

### CUSTOMER [#customer]

`CUSTOMER`

Sort orders by customer.

### PAYMENT [#payment]

`PAYMENT`

Sort orders by payment status.

:::warning[Deprecated]
The legacy Payments API is deprecated and will be removed. Use the Transactions API instead.
:::


### FULFILLMENT_STATUS [#fulfillment-status]

`FULFILLMENT_STATUS`

Sort orders by fulfillment status.

:::warning[Deprecated]
Use `STATUS` instead.
:::


### STATUS [#status]

`STATUS`

Sort orders by order status.
