Requests deletion of an invoice. 



<Permissions label="Requires one of the following permissions" values="MANAGE_ORDERS" />



Triggers the following webhook events:
- INVOICE_DELETED (async): An invoice was requested to delete.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [INVOICE_DELETED], syncEvents: [])
```



```graphql
invoiceRequestDelete(id: ID!): InvoiceRequestDelete
```
