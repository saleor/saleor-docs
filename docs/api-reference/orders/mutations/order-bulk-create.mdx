## Arguments

### errorPolicy [#error-policy]

**`errorPolicy`** · [`ErrorPolicyEnum`](/api-reference/miscellaneous/enums/error-policy-enum)

Policies of error handling. DEFAULT: REJECT_EVERYTHING

### orders [#orders]

**`orders`** · [`[OrderBulkCreateInput!]!`](/api-reference/orders/inputs/order-bulk-create-input)

Input list of orders to create. Orders limit: 50.

### stockUpdatePolicy [#stock-update-policy]

**`stockUpdatePolicy`** · [`StockUpdatePolicyEnum`](/api-reference/miscellaneous/enums/stock-update-policy-enum)

Determine how stock should be updated, while processing the order. DEFAULT: UPDATE - Only do update, if there is enough stocks.
