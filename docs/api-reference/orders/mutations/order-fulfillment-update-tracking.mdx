Updates a fulfillment for an order. 



<Permissions label="Requires one of the following permissions" values="MANAGE_ORDERS" />



Triggers the following webhook events:
- FULFILLMENT_TRACKING_NUMBER_UPDATED (async): Fulfillment tracking number is updated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [FULFILLMENT_TRACKING_NUMBER_UPDATED], syncEvents: [])
```



```graphql
orderFulfillmentUpdateTracking(id: ID!, input: FulfillmentUpdateTrackingInput!): FulfillmentUpdateTracking
```
