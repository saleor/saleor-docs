Request an invoice for the order using plugin. 



<Permissions label="Requires one of the following permissions" values="MANAGE_ORDERS" />



Triggers the following webhook events:
- INVOICE_REQUESTED (async): An invoice was requested.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [INVOICE_REQUESTED], syncEvents: [])
```



```graphql
invoiceRequest(number: String, orderId: ID!): InvoiceRequest
```

## Arguments

### number [#number]

**`number`** · [`String`](/api-reference/miscellaneous/scalars/string)

Invoice number, if not provided it will be generated.

### orderId [#order-id]

**`orderId`** · [`ID!`](/api-reference/miscellaneous/scalars/id)

ID of the order related to invoice.
