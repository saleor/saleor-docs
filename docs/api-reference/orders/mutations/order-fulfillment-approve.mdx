Approve existing fulfillment. 



<Permissions label="Requires one of the following permissions" values="MANAGE_ORDERS" />



Triggers the following webhook events:
- FULFILLMENT_APPROVED (async): Fulfillment is approved.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [FULFILLMENT_APPROVED], syncEvents: [])
```



```graphql
orderFulfillmentApprove(allowStockToBeExceeded: Boolean = false, id: ID!, notifyCustomer: Boolean!): FulfillmentApprove
```

## Arguments

### allowStockToBeExceeded [#allow-stock-to-be-exceeded]

**`allowStockToBeExceeded`** · [`Boolean`](/api-reference/miscellaneous/scalars/boolean)

True if stock could be exceeded.

Default: `false`.

### id [#id]

**`id`** · [`ID!`](/api-reference/miscellaneous/scalars/id)

ID of a fulfillment to approve.

### notifyCustomer [#notify-customer]

**`notifyCustomer`** · [`Boolean!`](/api-reference/miscellaneous/scalars/boolean)

True if confirmation email should be send.
