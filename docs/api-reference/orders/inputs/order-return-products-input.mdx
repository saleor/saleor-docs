```graphql
input OrderReturnProductsInput {
  orderLines: [OrderReturnLineInput!]
  fulfillmentLines: [OrderReturnFulfillmentLineInput!]
  amountToRefund: PositiveDecimal
  includeShippingCosts: Boolean = false
  refund: Boolean = false
  reason: String
  reasonReference: ID
}
```


## Fields

### orderLines [#order-lines]

**`orderLines`** · [`[OrderReturnLineInput!]`](/api-reference/orders/inputs/order-return-line-input)

List of unfulfilled lines to return.
### fulfillmentLines [#fulfillment-lines]

**`fulfillmentLines`** · [`[OrderReturnFulfillmentLineInput!]`](/api-reference/orders/inputs/order-return-fulfillment-line-input)

List of fulfilled lines to return.
### amountToRefund [#amount-to-refund]

**`amountToRefund`** · [`PositiveDecimal`](/api-reference/miscellaneous/scalars/positive-decimal)

The total amount of refund when the value is provided manually.
### includeShippingCosts [#include-shipping-costs]

**`includeShippingCosts`** · [`Boolean`](/api-reference/miscellaneous/scalars/boolean)

If true, Saleor will refund shipping costs. If amountToRefund is providedincludeShippingCosts will be ignored.

Default: `false`.
### refund [#refund]

**`refund`** · [`Boolean`](/api-reference/miscellaneous/scalars/boolean)

If true, Saleor will call refund action for all lines.

Default: `false`.
### reason [#reason]

**`reason`** · [`String`](/api-reference/miscellaneous/scalars/string)

Reason for returning this order.

### reasonReference [#reason-reference]

**`reasonReference`** · [`ID`](/api-reference/miscellaneous/scalars/id)

ID of a `Page` (Model) to reference in reason for this return.
