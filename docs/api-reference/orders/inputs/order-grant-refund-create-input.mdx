```graphql
input OrderGrantRefundCreateInput {
  amount: Decimal
  reason: String
  reasonReference: ID

  transactionId: ID!

```


## Fields

### amount [#amount]

**`amount`** · [`Decimal`](/api-reference/miscellaneous/scalars/decimal)

Amount of the granted refund. If not provided, the amount will be calculated automatically based on provided `lines` and `grantRefundForShipping`.
### reason [#reason]

**`reason`** · [`String`](/api-reference/miscellaneous/scalars/string)

Reason of the granted refund.
### reasonReference [#reason-reference]

**`reasonReference`** · [`ID`](/api-reference/miscellaneous/scalars/id)

ID of a `Page` (Model) to reference in reason.

<Badge variant="accent">Added in Saleor 3.22</Badge>
### lines [#lines]

**`lines`** · [`[OrderGrantRefundCreateLineInput!]`](/api-reference/orders/inputs/order-grant-refund-create-line-input)

Lines to assign to granted refund.
### grantRefundForShipping [#grant-refund-for-shipping]

**`grantRefundForShipping`** · [`Boolean`](/api-reference/miscellaneous/scalars/boolean)

Determine if granted refund should include shipping costs.
### transactionId [#transaction-id]

**`transactionId`** · [`ID!`](/api-reference/miscellaneous/scalars/id)

The ID of the transaction item related to the granted refund. If `amount` provided in the input, the transaction.chargedAmount needs to be equal or greater than provided `amount`.If `amount` is not provided in the input and calculated automatically by Saleor, the `min(calculatedAmount, transaction.chargedAmount)` will be used. Field required starting from Saleor 3.21.

<Badge variant="accent">Added in Saleor 3.20</Badge>
