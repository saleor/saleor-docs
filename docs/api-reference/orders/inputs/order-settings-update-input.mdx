## Fields

### automaticallyConfirmAllNewOrders [#automatically-confirm-all-new-orders]

**`automaticallyConfirmAllNewOrders`** · [`Boolean`](/api-reference/miscellaneous/scalars/boolean)

When disabled, all new orders from checkout will be marked as unconfirmed. When enabled orders from checkout will become unfulfilled immediately. By default set to True
### automaticallyFulfillNonShippableGiftCard [#automatically-fulfill-non-shippable-gift-card]

**`automaticallyFulfillNonShippableGiftCard`** · [`Boolean`](/api-reference/miscellaneous/scalars/boolean)

When enabled, all non-shippable gift card orders will be fulfilled automatically. By default set to True.
