Calculates available delivery options for a checkout.

<Badge variant="accent">Added in Saleor 3.23</Badge>

Triggers the following webhook events:
- SHIPPING_LIST_METHODS_FOR_CHECKOUT (sync): Triggered to fetch external shipping methods.
- CHECKOUT_FILTER_SHIPPING_METHODS (sync): Triggered to filter shipping methods.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [], syncEvents: [SHIPPING_LIST_METHODS_FOR_CHECKOUT, CHECKOUT_FILTER_SHIPPING_METHODS])
```



```graphql
deliveryOptionsCalculate(id: ID!): DeliveryOptionsCalculate
```
