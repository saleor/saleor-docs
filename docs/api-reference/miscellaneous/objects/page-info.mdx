The Relay compliant `PageInfo` type, containing data necessary to paginate this connection.



```graphql
type PageInfo {
  hasNextPage: Boolean!
  hasPreviousPage: Boolean!
  startCursor: String
  endCursor: String
}
```


## Fields

### hasNextPage [#has-next-page]

**`hasNextPage`** · [`Boolean!`](/api-reference/miscellaneous/scalars/boolean)

When paginating forwards, are there more items?
### hasPreviousPage [#has-previous-page]

**`hasPreviousPage`** · [`Boolean!`](/api-reference/miscellaneous/scalars/boolean)

When paginating backwards, are there more items?
### startCursor [#start-cursor]

**`startCursor`** · [`String`](/api-reference/miscellaneous/scalars/string)

When paginating backwards, the cursor to continue.
### endCursor [#end-cursor]

**`endCursor`** · [`String`](/api-reference/miscellaneous/scalars/string)

When paginating forwards, the cursor to continue.
