Lists current announcements that the user should see.

```graphql
type Announcement {
  createdAt: DateTime!
  updatedAt: DateTime!
  title: String!
  messageHtml: String!
  importance: AnnouncementImportanceEnum!
  type: String!
  extra: Metadata!
}
```

### Fields

#### [<code>createdAt</code>](#created-at)<Bullet />[<code>DateTime!</code>](/api-reference/miscellaneous/scalars/date-time.mdx) \{#created-at\}

The date & time at which this announcement was created.

#### [<code>updatedAt</code>](#updated-at)<Bullet />[<code>DateTime!</code>](/api-reference/miscellaneous/scalars/date-time.mdx) \{#updated-at\}

The date & time at which this announcement was last updated.

#### [<code>title</code>](#title)<Bullet />[<code>String!</code>](/api-reference/miscellaneous/scalars/string.mdx) \{#title\}

The announcement's title.

#### [<code>messageHtml</code>](#message-html)<Bullet />[<code>String!</code>](/api-reference/miscellaneous/scalars/string.mdx) \{#message-html\}

The announcement's description, may contain HTML formatting.

#### [<code>importance</code>](#importance)<Bullet />[<code>AnnouncementImportanceEnum!</code>](/api-reference/shop/enums/announcement-importance-enum.mdx) \{#importance\}

Determine the how critical the announcement is. UNSET if no severity level was defined for this announcement.

#### [<code>type</code>](#type)<Bullet />[<code>String!</code>](/api-reference/miscellaneous/scalars/string.mdx) \{#type\}

The announcement's type, for example "CUSTOM". Used to programatically distinguish between message types thus allowing to render the message differently, and allows to know the expected shape for the `extra` field.

#### [<code>extra</code>](#extra)<Bullet />[<code>Metadata!</code>](/api-reference/miscellaneous/scalars/metadata.mdx) \{#extra\}

Additional information about this announcement.
