Lists current announcements that the user should see.



```graphql
type Announcement {
  createdAt: DateTime!
  updatedAt: DateTime!
  title: String!
  messageHtml: String!
  importance: AnnouncementImportanceEnum!
  type: String!
  extra: Metadata!
}
```


## Fields

### createdAt [#created-at]

**`createdAt`** · [`DateTime!`](/api-reference/miscellaneous/scalars/date-time)

The date & time at which this announcement was created.
### updatedAt [#updated-at]

**`updatedAt`** · [`DateTime!`](/api-reference/miscellaneous/scalars/date-time)

The date & time at which this announcement was last updated.
### title [#title]

**`title`** · [`String!`](/api-reference/miscellaneous/scalars/string)

The announcement's title.
### messageHtml [#message-html]

**`messageHtml`** · [`String!`](/api-reference/miscellaneous/scalars/string)

The announcement's description, may contain HTML formatting.
### importance [#importance]

**`importance`** · [`AnnouncementImportanceEnum!`](/api-reference/shop/enums/announcement-importance-enum)

Determine the how critical the announcement is. UNSET if no severity level was defined for this announcement.
### type [#type]

**`type`** · [`String!`](/api-reference/miscellaneous/scalars/string)

The announcement's type, for example "CUSTOM". Used to programatically distinguish between message types thus allowing to render the message differently, and allows to know the expected shape for the `extra` field.
### extra [#extra]

**`extra`** · [`Metadata!`](/api-reference/miscellaneous/scalars/metadata)

Additional information about this announcement.
