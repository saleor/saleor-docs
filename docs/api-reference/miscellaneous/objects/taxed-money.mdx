Represents a monetary value with taxes. In cases where taxes were not applied, net and gross values will be equal.



```graphql
type TaxedMoney {
  currency: String!
  gross: Money!
  net: Money!
  tax: Money!
}
```


## Fields

### currency [#currency]

**`currency`** · [`String!`](/api-reference/miscellaneous/scalars/string)

Currency code.
### gross [#gross]

**`gross`** · [`Money!`](/api-reference/miscellaneous/objects/money)

Amount of money including taxes.
### net [#net]

**`net`** · [`Money!`](/api-reference/miscellaneous/objects/money)

Amount of money without taxes.
### tax [#tax]

**`tax`** · [`Money!`](/api-reference/miscellaneous/objects/money)

Amount of taxes.
