Represents amount of money in specific currency.



```graphql
type Money {
  currency: String!
  amount: Float!
  fractionalAmount: Int!
  fractionDigits: Int!
}
```


## Fields

### currency [#currency]

**`currency`** · [`String!`](/api-reference/miscellaneous/scalars/string)

Currency code.
### amount [#amount]

**`amount`** · [`Float!`](/api-reference/miscellaneous/scalars/float)

Amount of money.
### fractionalAmount [#fractional-amount]

**`fractionalAmount`** · [`Int!`](/api-reference/miscellaneous/scalars/int)

Amount of money represented as an integer in the smallest currency unit.
### fractionDigits [#fraction-digits]

**`fractionDigits`** · [`Int!`](/api-reference/miscellaneous/scalars/int)

Number of digits after the decimal point in the currency.
