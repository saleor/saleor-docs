Represents a job data of exported file.



```graphql
type ExportFile implements Node & Job {
  id: ID!
  status: JobStatusEnum!
  createdAt: DateTime!
  updatedAt: DateTime!
  message: String
  url: String
  events: [ExportEvent!]
  user: User
  app: App
}
```
