Dismissal information for an app problem.

<Badge variant="accent">Added in Saleor 3.22</Badge>



```graphql
type AppProblemDismissed {
  by: AppProblemDismissedByEnum!
  user: User
  userEmail: String
}
```


## Fields

### by [#by]

**`by`** · [`AppProblemDismissedByEnum!`](/api-reference/apps/enums/app-problem-dismissed-by-enum)

Whether the problem was dismissed by an App or a User.

<Badge variant="accent">Added in Saleor 3.22</Badge>
### user [#user]

**`user`** · [`User`](/api-reference/users/objects/user)

The user who dismissed this problem. Null if dismissed by an app or the user was deleted.

<Badge variant="accent">Added in Saleor 3.22</Badge>



<Permissions label="Requires one of the following permissions" values="MANAGE_STAFF" />


### userEmail [#user-email]

**`userEmail`** · [`String`](/api-reference/miscellaneous/scalars/string)

Email of the user who dismissed this problem. Preserved even if the user is deleted.

<Badge variant="accent">Added in Saleor 3.22</Badge>



<Permissions label="Requires one of the following permissions" values="AUTHENTICATED_STAFF_USER" />
