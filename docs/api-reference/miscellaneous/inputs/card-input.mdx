Card data used to check a payment balance.

The legacy Payments API is deprecated and will be removed. Use the Transactions API instead.



```graphql
input CardInput {
  code: String!
  cvc: String
  money: MoneyInput!
}
```


## Fields

### code [#code]

**`code`** · [`String!`](/api-reference/miscellaneous/scalars/string)

Payment method nonce, a token returned by the appropriate provider's SDK.
### cvc [#cvc]

**`cvc`** · [`String`](/api-reference/miscellaneous/scalars/string)

Card security code.
### money [#money]

**`money`** · [`MoneyInput!`](/api-reference/miscellaneous/inputs/money-input)

Information about currency and amount.
