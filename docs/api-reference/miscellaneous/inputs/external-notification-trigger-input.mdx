## Fields

### ids [#ids]

**`ids`** · [`[ID!]!`](/api-reference/miscellaneous/scalars/id)

**`extraPayload`** · [`JSONString`](/api-reference/miscellaneous/scalars/jsonstring)

**`externalEventType`** · [`String!`](/api-reference/miscellaneous/scalars/string)

External event type. This field is passed to a plugin as an event type.
