Returns a list of all translatable items of a given kind.



<Permissions label="Requires one of the following permissions" values="MANAGE_TRANSLATIONS" />





```graphql
translations(kind: TranslatableKinds!, before: String, after: String, first: Int, last: Int): TranslatableItemConnection
```

## Returns

[`TranslatableItemConnection`](/api-reference/miscellaneous/objects/translatable-item-connection)

<details>
<summary>Show return type</summary>


```graphql
type TranslatableItemConnection {
  pageInfo: PageInfo!
  edges: [TranslatableItemEdge!]!
  totalCount: Int
}
```


</details>

## Arguments

### kind [#kind]

**`kind`** · [`TranslatableKinds!`](/api-reference/miscellaneous/enums/translatable-kinds)

Kind of objects to retrieve.

### before [#before]

**`before`** · [`String`](/api-reference/miscellaneous/scalars/string)

Return the elements in the list that come before the specified cursor.

### after [#after]

**`after`** · [`String`](/api-reference/miscellaneous/scalars/string)

Return the elements in the list that come after the specified cursor.

### first [#first]

**`first`** · [`Int`](/api-reference/miscellaneous/scalars/int)

Retrieve the first n elements from the list. Note that the system only allows fetching a maximum of 100 objects in a single query.

### last [#last]

**`last`** · [`Int`](/api-reference/miscellaneous/scalars/int)

Retrieve the last n elements from the list. Note that the system only allows fetching a maximum of 100 objects in a single query.
