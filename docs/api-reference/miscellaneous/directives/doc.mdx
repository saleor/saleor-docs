Groups fields and operations into named groups.



```graphql
"""Groups fields and operations into named groups."""
directive @doc(
  """Name of the grouping category"""
  category: String!
) on ENUM | FIELD | FIELD_DEFINITION | INPUT_OBJECT | OBJECT | INTERFACE
```


## Locations

`ENUM`, `FIELD`, `FIELD_DEFINITION`, `INPUT_OBJECT`, `OBJECT`, `INTERFACE`
