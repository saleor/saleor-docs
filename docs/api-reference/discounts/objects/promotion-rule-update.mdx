Updates an existing promotion rule. 



<Permissions label="Requires one of the following permissions" values="MANAGE_DISCOUNTS" />



Triggers the following webhook events:
- PROMOTION_RULE_UPDATED (async): A promotion rule was updated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [PROMOTION_RULE_UPDATED], syncEvents: [])
```

type PromotionRuleUpdate {
  errors: [PromotionRuleUpdateError!]!

}
