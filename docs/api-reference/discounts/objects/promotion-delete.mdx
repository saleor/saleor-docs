Deletes a promotion. 



<Permissions label="Requires one of the following permissions" values="MANAGE_DISCOUNTS" />



Triggers the following webhook events:
- PROMOTION_DELETED (async): A promotion was deleted.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [PROMOTION_DELETED], syncEvents: [])
```



```graphql
type PromotionDelete {
  errors: [PromotionDeleteError!]!
  promotion: Promotion
}
```
