Deletes voucher codes.

Added in Saleor 3.18. 



<Permissions label="Requires one of the following permissions" values="MANAGE_DISCOUNTS" />



Triggers the following webhook events:
- VOUCHER_CODES_DELETED (async): A voucher codes were deleted.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [VOUCHER_CODES_DELETED], syncEvents: [])
```



```graphql
type VoucherCodeBulkDelete {
  count: Int!
  errors: [VoucherCodeBulkDeleteError!]!
}
```
