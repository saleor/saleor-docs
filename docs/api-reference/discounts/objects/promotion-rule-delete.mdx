Deletes a promotion rule. 



<Permissions label="Requires one of the following permissions" values="MANAGE_DISCOUNTS" />



Triggers the following webhook events:
- PROMOTION_RULE_DELETED (async): A promotion rule was deleted.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [PROMOTION_RULE_DELETED], syncEvents: [])
```
