Creates a new promotion. 



<Permissions label="Requires one of the following permissions" values="MANAGE_DISCOUNTS" />



Triggers the following webhook events:
- PROMOTION_CREATED (async): A promotion was created.
- PROMOTION_STARTED (async): Optionally called if promotion was started.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [PROMOTION_CREATED, PROMOTION_STARTED], syncEvents: [])
```

type PromotionCreate {
  errors: [PromotionCreateError!]!
  promotion: Promotion
