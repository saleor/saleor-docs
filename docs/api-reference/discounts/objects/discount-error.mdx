```graphql
type DiscountError {
  field: String
  message: String
  products: [ID!]
  code: DiscountErrorCode!
  channels: [ID!]
  voucherCodes: [String!]
}
```


## Fields

### field [#field]

**`field`** · [`String`](/api-reference/miscellaneous/scalars/string)

Name of a field that caused the error. A value of `null` indicates that the error isn't associated with a particular field.
### message [#message]

**`message`** · [`String`](/api-reference/miscellaneous/scalars/string)

The error message.
### products [#products]

**`products`** · [`[ID!]`](/api-reference/miscellaneous/scalars/id)

List of products IDs which causes the error.
### code [#code]

**`code`** · [`DiscountErrorCode!`](/api-reference/discounts/enums/discount-error-code)

The error code.
### channels [#channels]

**`channels`** · [`[ID!]`](/api-reference/miscellaneous/scalars/id)

List of channels IDs which causes the error.
### voucherCodes [#voucher-codes]

**`voucherCodes`** · [`[String!]`](/api-reference/miscellaneous/scalars/string)

List of voucher codes which causes the error.
