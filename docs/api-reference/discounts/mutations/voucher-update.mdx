Updates a voucher. 



<Permissions label="Requires one of the following permissions" values="MANAGE_DISCOUNTS" />



Triggers the following webhook events:
- VOUCHER_UPDATED (async): A voucher was updated.
- VOUCHER_CODES_CREATED (async): A voucher code was created.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [VOUCHER_UPDATED, VOUCHER_CODES_CREATED], syncEvents: [])
```



```graphql
voucherUpdate(externalReference: String, id: ID, input: VoucherInput!): VoucherUpdate
```
