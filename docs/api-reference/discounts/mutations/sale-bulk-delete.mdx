Deletes sales. 



<Permissions label="Requires one of the following permissions" values="MANAGE_DISCOUNTS" />



Triggers the following webhook events:
- SALE_DELETED (async): A sale was deleted.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [SALE_DELETED], syncEvents: [])
```



```graphql
saleBulkDelete(ids: [ID!]!): SaleBulkDelete
```
