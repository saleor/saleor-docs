Deletes a voucher. 



<Permissions label="Requires one of the following permissions" values="MANAGE_DISCOUNTS" />



Triggers the following webhook events:
- VOUCHER_DELETED (async): A voucher was deleted.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [VOUCHER_DELETED], syncEvents: [])
```



```graphql
voucherDelete(externalReference: String, id: ID): VoucherDelete
```
