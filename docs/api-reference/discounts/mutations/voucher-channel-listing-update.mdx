Manage voucher's availability in channels. 



<Permissions label="Requires one of the following permissions" values="MANAGE_DISCOUNTS" />



Triggers the following webhook events:
- VOUCHER_UPDATED (async): A voucher was updated.



**Applied directives**

```graphql
@webhookEventsInfo(asyncEvents: [VOUCHER_UPDATED], syncEvents: [])
```



```graphql
voucherChannelListingUpdate(id: ID!, input: VoucherChannelListingInput!): VoucherChannelListingUpdate
```
