<div>
This guide will help you set up a [Saleor storefront](https://github.com/saleor/storefront/) in your local environment.

The storefront is a Next.js application. It requires Saleor 3.23 or later and Node.js 24.

</div>

<Steps titleSize="h3">
<Step title={"Install project"}>
<div>
<span id="install-project" />
Clone repo and install dependencies. Alternatively, bootstrap the project with the [Saleor CLI](https://github.com/saleor/saleor-cli): `saleor storefront create --url https://{your_domain}.saleor.cloud/graphql/`.

</div>
<div>
            ```bash
            git clone https://github.com/saleor/storefront.git saleor-storefront
            cd saleor-storefront
            pnpm i
            ```
</div>
</Step>

<Step title={"Copy variables"}>
<div>
<span id="copy-variables" />
Copy environment variables from .env.example to .env:
</div>
<div>
            ```bash
            cp .env.example .env
            ```
</div>
</Step>

<Step title={"Add backend URL"}>
<div>
<span id="add-backend-url" />
Use a [free test project](/quickstart/cloud#signup) at Saleor Cloud to start quickly with the backend.
Alternatively, you can [run Saleor locally](/quickstart/running-locally) using Docker.
</div>

<div>
            ```bash title=".env"
            # Add backend address
            # Make sure to add slash at the end:
            NEXT_PUBLIC_SALEOR_API_URL=https://{your_domain}.saleor.cloud/graphql/

            # Local example
            # NEXT_PUBLIC_SALEOR_API_URL=http://localhost:8000/graphql/

            # Channel slug from Dashboard → Configuration → Channels
            NEXT_PUBLIC_DEFAULT_CHANNEL=default-channel
            ```
</div>
</Step>

<Step title={"Run project"}>
<div>
<span id="run-project" />

Run the development server.
</div>
<div>
            ```bash
            pnpm run dev
            ```
</div>
</Step>

<Step title={"Edit a product"}>
<div>
<span id="edit-a-product" />
1. Find any product page in the storefront
2. Go to the dashboard of your Saleor instance and change that product information, such as name, price, or description.
3. Refresh the product page in the storefront; notice that information has not changed. Product pages are cached and refreshed at most once an hour.
4. To see changes right away, install the [Saleor Paper app](https://github.com/saleor/saleor-paper-app) from Dashboard → Extensions (Saleor Cloud only). It sets up webhooks that refresh the cached page when you save a product.
</div>
</Step>

<Step title={"Edit a query"}>
<div>
<span id="edit-a-query" />
1. In ```src/graphql``` folder, find a query you want to edit. For example add field ```rating``` to ```ProductDetails.graphql```.
2. Generate types and queries by running the following command:

This would update types and queries for the new field, which we will use in the next step. Queries used by the checkout are generated with `pnpm run generate:checkout`.
</div>
<div>
            ```bash
            pnpm run generate
            ```
</div>
</Step>

<Step title={"Update product page"}>
<div>
<span id="update-product-page" />
1. Open ```src/app/(storefront)/[locale]/[channel]/(main)/products/[slug]/page.tsx``` file.
2. You will be able now to render the newly added field ```rating``` in the product page. Notice that the new field can be autocompleted by Typescript.
</div>
<div>
            ```jsx title="src/app/(storefront)/[locale]/[channel]/(main)/products/[slug]/page.tsx"

            async function ProductShell({ params: paramsPromise }) {
                // ...
                const rating = product.rating;
                // ...
            }
            ```
</div>
</Step>

</Steps>
