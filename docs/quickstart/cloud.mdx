Create a Saleor sandbox and make your first GraphQL request. By the end, you will have a store, a Dashboard, and an API endpoint ready for your storefront or app.

**You need:** a Saleor Cloud account and a browser. No local installation is required.

<Steps>
<Step title="Create an account">
<span id="signup" />
[Sign up for Saleor Cloud](https://cloud.saleor.io/signup), then open your project.
</Step>

<Step title="Create a sandbox">
<span id="create-a-sandbox" />
Create a sandbox in the region closest to your project. Use sample data if you want to explore products and checkout immediately.

Wait until the environment is ready. Its details page provides links to the Dashboard and API.
</Step>

<Step title="Explore your store">
<span id="explore-the-dashboard" />
Open the Dashboard and browse **Products**. With sample data, you should see a populated catalog. Keep the Dashboard open so you can compare it with API results.
</Step>

<Step title="Make your first API request">
Copy the API URL from your environment details. Select **Run** below to configure the Playground, then run the query. This public query does not need a token.

<GraphQLExample exampleId="shop" />

**Expected result:** a JSON response containing `data.shop.name` with your store's name.

If the request fails, check that the environment is ready and that you copied the API endpoint, ending in `/graphql/`, rather than the Dashboard URL.
</Step>
</Steps>

## Manage sandbox data

Snapshots let you save and restore an environment while experimenting. Read the [environment data management guide](/cloud/environment#data-management) when you need this workflow.

<details>
<summary>Optional: practice saving and restoring a snapshot</summary>

<Steps>
<Step title={"Create a snapshot"}>
<div>
<span id="create-a-snapshot" />
1. Try to modify any data (for example, deleting or editing a product) and create a snapshot of the store to save the current state of the store.
2. In the sandbox details page, use **Create snapshot**.
3. Give the snapshot a name **Staging snapshot**.
</div>
</Step>

<Step title={"Clear data"}>
<div>
<span id="clear-data" />
We can completely erase data from the DB to start from scratch.

In the sandbox **Danger** settings, use **Clear database**.

This will remove all data from the database, making the dashboard empty as a result.
</div>
</Step>

<Step title={"Use snapshot"}>
<div>
<span id="use-snapshot" />
Use **Restore from snapshot** to back the data we saved in the previous step.

Snapshots can be used across different sandboxes. You can now also create a new sandbox using the snapshot.

Go to **Project** -> **New sandbox** -> **Create from snapshot**.

</div>
</Step>


</Steps>
</details>
